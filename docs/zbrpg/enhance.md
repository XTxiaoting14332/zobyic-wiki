# 💪 装备强化

::: info
强化是装备变强的主线，最高 **+30**。这页讲怎么强化、失败会怎样，以及强化到底加了什么 📈
:::

---

## “🤨 什么装备能强化？”

| 类型             | 能强化吗                  |
| ---------------- | ------------------------- |
| 铁匠铺锻造的武器 | ✅ 能                     |
| 铁匠铺锻造的护甲 | ✅ 能                     |
| 镐、铲、锄等工具 | ❌ 不能，工具没有战斗属性 |

---

## “🔨 怎么强化？”

1. 右键铁匠 NPC，在「特殊材料」里做好 **锻造锤**
2. 打开「装备强化」，放入要强化的装备
3. 每次强化消耗锻造锤和金币，等级越高，金币越多、成功率越低

> “失败了是不是会掉级？？我不敢点了……”

放心点！

::: tip 失败不降级 ✅
失败只损失这次的锻造锤和金币，等级**保持不变**。
:::

::: warning 全服播报 📢
冲 **+25 及以上** 时，不管成功还是失败，都会向全服广播 ~~失败了全服都知道~~
:::

---

## “📈 强化到底加了什么？”

| 装备      | 强化提升                           |
| --------- | ---------------------------------- |
| ⚔️ 武器 | 攻击伤害                           |
| 🛡️ 护甲 | 物理防御，以及护甲自带的攻击和生命 |

加上去的部分会在 lore 里用<span style="color:#16a34a">绿色括号</span>显示，比如 `53.5 (+32.1)`。
