# 📊 属性、套装与灵魂绑定

::: info
这页是「规则说明书」：属性有哪些、套装怎么生效、防御怎么算、灵魂绑定会怎样 📖
:::

---

## “🧐 装备上这些属性都是啥？”

攻击伤害、暴击率、暴击伤害、攻击速度、物理防御、生命值。部分装备还带 **宝石槽** 💎

---

## “👕 套装效果怎么触发？”

同一系列的护甲穿够件数就生效，件数越多档位越高。目前四件套效果：

| 套装      | 四件套效果            |
| --------- | --------------------- |
| 🖤 黑曜石 | 生命 +6，打怪伤害 +3% |
| 🏚️ 地牢 | 生命 +8，打怪伤害 +4% |

---

## “🛡️ 防御堆越高越好吗？”

> “我把防御堆到几百，是不是就无敌了？”

<span style="color:#e8590c">并不会</span> 😅 防御越高减伤越多，但收益会越来越小。


---

## “❤️ 我的血条怎么变短了？”

生命值很高时，底部红心会**按比例压缩**显示，比如 184/200 显示大约 9 颗心。只是显示变了，实际血量一点没少 👌

---

## “灵魂绑定是什么？”

绑定后，lore 最后一行会显示「灵魂绑定：玩家名」。

| 情况           | 会怎样                                                          |
| -------------- | --------------------------------------------------------------- |
| 什么时候绑定   | 从铁匠 NPC 领取时绑定给领取人；旧装备第一次拿在主手或穿上时绑定 |
| 能丢吗         | ❌ Q 键丢、拖出背包都会被拦下 ✅ 但可以放进箱子                 |
| 别人拿到能用吗 | ❌ 不能攻击、射箭、挖掘、穿戴，也不能强化或重铸                 |
| 死了会掉吗     | ❌ 不掉，复活后回到背包                                         |

😏 所以绑定装备被朋友顺走了也不用慌，他拿着也没用，要回来就行。
