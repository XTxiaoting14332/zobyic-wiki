# T4·地牢系列装备

地牢系列是冒险者在完成初期成长后，通过主城铁匠铺进一步打造的 T4 阶段装备。玩家需要收集地牢合金与刷怪笼残骸，再将它们锻造成武器、护甲与工具。**同种装备在锻造时会随机生成基础属性**，最高可强化至 **+30**。

::: warning 数值以服务器为准
本页所有数值仅供参考，一切以服务器内实际数值为准。
:::

## 地牢合金

![](/uploads/img-1793232293259-05od6.png)

一种用于制造地牢系列装备的特殊合金，能够锻造成坚固的护甲、锋利的兵器与耐用的工具。

地牢合金是打造**地牢系列武器、护甲及工具**的核心材料。

**获取方式：** 使用刷怪笼残骸锻造而成。

## 刷怪笼残骸

![](/uploads/img-1793232341201-uq73a.png)

从破碎刷怪笼中回收的残骸，是地牢系列装备配方中不可缺少的另一种材料。不同部位的装备，对地牢合金和刷怪笼残骸的需求各不相同。

**获取方式：** 通过挖掘原版刷怪笼掉落。

## 地牢套装

地牢护甲由厚重的合金甲片制成，适合前往危险遗迹与地牢探索。四件护甲均可提供**物理防御、额外生命与攻击伤害**，玩家能够根据自己的需求挑选初始属性更好的装备。

地牢装备在锻造完成时会生成随机属性，因此即便是同一种装备，也可能拥有不同的初始数值。装备最高可强化至 **+30**。

## 地牢武器

地牢系列包含**地牢收割者**和**地牢伐木者**两把近战武器。两者均拥有随机攻击伤害、暴击概率和额外暴击伤害，可以通过铁匠强化进一步提升攻击力。

地牢收割者拥有更快的攻击速度；地牢伐木者攻击速度较慢，但单次攻击伤害更高，适合不同的战斗方式。

### 地牢收割者

![](/uploads/img-1793232562114-1lcpv.png)

利刃闪烁着诅咒的黯光，仿佛要收割一切阻挡前路的生灵。地牢收割者是一把攻击速度较快的近战长剑，适合持续攻击怪物与 BOSS。

| 属性         | 数值       |
| ------------ | ---------- |
| 初始攻击伤害 | 13.4–18.4 |
| +30 攻击伤害 | 33.5–46.0 |
| 暴击概率     | 15%–20%   |
| 额外暴击伤害 | +15%–25%  |
| 攻击速度     | 1.6        |

**锻造消耗：** 地牢合金 ×7、刷怪笼残骸 ×4。

### 地牢伐木者

![](/uploads/img-1793232581765-ynlsr.png)

沉重的合金斧刃蓄满力量，能够劈开朽木与强敌。相比地牢收割者，它拥有更高的单次攻击伤害，但攻击速度较慢，适合偏好重击战斗的冒险者。

| 属性         | 数值       |
| ------------ | ---------- |
| 初始攻击伤害 | 16.4–21.4 |
| +30 攻击伤害 | 41.0–53.5 |
| 暴击概率     | 10%–15%   |
| 额外暴击伤害 | +15%–25%  |
| 攻击速度     | 1.0        |

**锻造消耗：** 地牢合金 ×9、刷怪笼残骸 ×4。

## 装备强化

前往主城铁匠铺，可以对地牢武器与护甲进行 **`+N` 强化**。强化上限为 **+30**，单次基础成功率为 **45%**，强化失败不降级，仅消耗对应锻造锤。强化后装备会根据自身的基础属性获得成长。

**注意：** 铁匠 `+N` 强化与星辉锻打的星级是两套独立系统。上表的 +30 数值不包含星辉锻打、宝石、附魔或其他额外加成。

## 锻造基本信息

每件地牢装备的铁匠锻造价格均为 **500 金币**，耗时 **60 秒**，锻造成功率 **100%**。
