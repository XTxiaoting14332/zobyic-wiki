# T5·黑曜石系列装备

黑曜石系列是冒险者进入 RPG 锻造体系后的第一阶段装备。通过主城铁匠铺，玩家可以制作黑曜石锭，并进一步锻造武器、护甲和工具。**同种装备在锻造时会随机生成基础属性**，最高可强化至 **+30**。

## 黑曜石锭

![](/uploads/img-1791875327818-7k7j2.png)由黑曜石、铁与煤炭经过特殊工艺熔炼而成的坚硬金属锭，内部蕴藏着炽热而稳定的力量。

黑曜石锭是打造**黑曜石系列武器、护甲及工具**的核心材料，也是冒险者迈入 RPG 装备体系的重要起点。

**获取方式：** 前往主城铁匠铺，在特殊材料锻造界面中制作。

## 黑曜石套装

黑曜石套装是冒险者成长初期的重要战斗装备。经过铁匠的精心锻造，它不仅拥有坚固的防御能力，还能为穿戴者提供额外的攻击伤害与生命值。

黑曜石装备在锻造完成时会生成随机属性，因此即使是同一种装备，也可能拥有不同的初始数值。装备最高可强化至 **+30**。

**套装效果：** 同时穿戴四件黑曜石护甲，额外获得 **6 点最大生命值**，并提高 **3% 对敌对生物造成的伤害**。

### 黑曜石头盔


由坚固的黑曜石合金打造，能够在危险的战斗中保护冒险者的头部。提供物理防御、额外生命与攻击伤害，可通过强化进一步提升属性。

| 属性     | +0 初始  | +30 满级 |
| -------- | -------- | -------- |
| 攻击伤害 | 1.0–2.0 | 4.0–8.0 |
| 物理防御 | 2.0      | 7.2      |
| 额外生命 | 1.0–2.0 | 4.0–8.0 |

**锻造消耗：** 黑曜石锭 ×12。

### 黑曜石胸甲


黑曜石套装中最重要的防护部件，厚重的合金甲片能够抵挡来自怪物的猛烈攻击。拥有较高的基础物理防御，并提供额外生命和攻击伤害，是近战冒险者的重要装备。

| 属性     | +0 初始  | +30 满级  |
| -------- | -------- | --------- |
| 攻击伤害 | 2.0–3.0 | 8.0–12.0 |
| 物理防御 | 5.0      | 18.0      |
| 额外生命 | 1.5–2.5 | 6.0–10.0 |

**锻造消耗：** 黑曜石锭 ×12。

### 黑曜石护腿


经过精密锻造的黑曜石护腿，在保证防护能力的同时兼顾行动灵活性。能够提供物理防御、额外生命和攻击伤害，适合长时间探索与战斗。

| 属性     | +0 初始  | +30 满级 |
| -------- | -------- | -------- |
| 攻击伤害 | 1.0–2.0 | 4.0–8.0 |
| 物理防御 | 3.5      | 12.6     |
| 额外生命 | 1.0–2.0 | 4.0–8.0 |

**锻造消耗：** 黑曜石锭 ×12。

### 黑曜石战靴


采用黑曜石合金制成的坚固战靴，可以在冒险中为穿戴者提供稳定的保护。拥有物理防御、额外生命与攻击属性，可通过强化提升战斗能力。

## 黑曜石武器

黑曜石武器由经过特殊熔炼的黑曜石合金制成，拥有高于普通武器的战斗潜力。武器在锻造时会随机生成攻击与暴击属性，通过强化可进一步提高攻击伤害。

### 黑曜石剑


锋利而坚固的黑曜石长剑，专为正面战斗打造，是冒险者前期探索遗迹、挑战怪物与 BOSS 的可靠武器。

| 属性         | 数值       |
| ------------ | ---------- |
| 初始攻击伤害 | 9.0–11.0  |
| +30 攻击伤害 | 22.5–27.5 |
| 暴击概率     | 15%–20%   |
| 额外暴击伤害 | +15%–25%  |
| 攻击速度     | 1.6        |

**锻造消耗：** 黑曜石锭 ×24。

### 黑曜石弓


使用特殊黑曜石合金打造的远程武器，适合在安全距离攻击强大的敌人。拥有随机远程伤害与暴击属性，并可以通过强化和力量附魔进一步提高输出能力。

| 属性         | 数值              |
| ------------ | ----------------- |
| 初始远程伤害 | 8.0–10.0         |
| +30 远程伤害 | 20.0–25.0        |
| 暴击概率     | 12%–17%          |
| 额外暴击伤害 | +15%–25%         |
| 力量附魔加成 | 每级远程伤害 +10% |

**锻造消耗：** 黑曜石锭 ×24。

### 黑曜石战斧


沉重而锋利的黑曜石战斧，以强大的单次攻击伤害著称。虽然攻击速度相对较慢，但拥有较高的基础伤害，适合喜欢重击战斗风格的冒险者。

| 属性         | 数值       |
| ------------ | ---------- |
| 初始攻击伤害 | 11.0–13.0 |
| +30 攻击伤害 | 27.5–32.5 |
| 暴击概率     | 10%–15%   |
| 额外暴击伤害 | +15%–25%  |
| 攻击速度     | 1.0        |

**锻造消耗：** 黑曜石锭 ×24。

## 黑曜石工具

黑曜石工具由坚固的合金材料打造，拥有优秀的耐久特性，适合进行长期资源采集。黑曜石镐、锹和锄各消耗**黑曜石锭 ×16**，当前不可强化。

## 装备强化

前往主城铁匠铺，消耗锻造锤对黑曜石武器与护甲进行强化。强化最高 **+30**，单次成功率 45%；失败仅消耗锻造锤，不降级。属性按锻造时的基础数值线性百分比成长。
