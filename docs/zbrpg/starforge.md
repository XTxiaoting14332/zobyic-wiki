# ⭐ 星级锻造

::: info
+30 不是终点！装备强化满了以后，还能用星级锻造继续变强 ✨
:::

---

## “😳 星级锻造是啥？”

> “我的剑已经 +30 了，接下来还能干嘛？”

输入 `/zsf` 打开星级锻造。它和 +N 强化是<span style="color:#e8590c">两套独立</span>的成长，互不影响。

| 对比       | 装备强化         | 星级锻造               |
| ---------- | ---------------- | ---------------------- |
| 怎么打开   | 右键铁匠 NPC     | 找到特殊铁砧           |
| 门槛       | 铁匠铺锻造的装备 | 装备必须先**+30**      |
| 用什么锤子 | 锻造锤           | 星锻锤                 |
| 成长方式   | +1 → +30        | 5 颗星，每次点亮 ¼ 颗 |

---

## “⭐ 星星怎么点亮？”

每件装备都显示 **5 颗星**。每次成功点亮 ¼ 颗：空星 → ¼ → ½ → ¾ → 满星，一颗满了再点下一颗。

每次敲击都会消耗星锻锤，还会播放锻打动画 🔨✨

::: warning 锤子别拿错
星锻锤和铁匠铺的锻造锤是**两种物品**，不能混用！
:::

😏 星级带来的攻击加成写在 RPG 攻击那一行的括号里，不单独占一行，别找半天找不到。

---

## “📋 告示板委托”

主城有一块 **告示板**，右键打开委托菜单。完成每日、每周委托，就能拿到奖励 🎁
