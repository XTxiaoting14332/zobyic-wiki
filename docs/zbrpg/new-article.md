# RPG 玩法教程

Zobyic Realms 的 RPG 玩法围绕一件事：在铁匠铺打造装备，再一步步把它变强。

## RPG 玩法是什么

一件装备的成长分三段：

1. **锻造**：用材料和金币在铁匠铺打出装备，基础属性随机生成。
2. **强化**：用锻造锤把装备从 +0 一路强化到 +30。
3. **星级锻造**：+30 之后，进入星锻系统点亮 5 颗星，继续提升攻击。
4. 持续更新中!

## 铁匠铺

Tips: 怎么进入 铁匠铺只能通过**铁匠 NPC** 进入：找到铁匠 NPC，右键它打开铁匠铺。 👍

主菜单有 5 块功能图块，右下角是「说明」和「关闭」按钮。

| 图块     | 用途                                         |
| -------- | -------------------------------------------- |
| 武器锻造 | 打造剑、斧、弓等武器，以及镐等工具           |
| 装备锻造 | 打造头盔、胸甲、护腿、靴子                   |
| 装备强化 | 用锻造锤给装备提升强化等级                   |
| 特殊材料 | 把原材料加工成合金等锻造材料，也能制作锻造锤 |
| 装备重铸 | 重新随机一件装备的基础属性                   |

锻造页会把所有系列的装备按页排列，用侧边翻页即可浏览。鼠标停在装备上可以看到它需要的材料、金币和属性范围。

## 锻造装备

1. 在「武器锻造」或「装备锻造」里点选想要的装备。
2. 背包里备齐材料和金币，确认锻造。
3. 装备进入锻造队列，等待计时结束。等待期间可以去做别的事。
4. 回到铁匠 NPC 领取装备。

info 属性是随机的 锻造菜单显示的是范围，例如攻击 `+6.0～8.0`。领取时会在范围内随机一次，之后永久保存。强化按这个基础值成长，所以基础值越高，强化后越强。 🎉️

## 装备强化

强化最高 **+30**。所有在铁匠铺锻造的武器和护甲都能强化；镐、铲、锄等工具不能强化。

1. 在「特殊材料」里制作锻造锤。
2. 打开「装备强化」，放入要强化的装备。
3. 每次强化消耗锻造锤和金币。等级越高，金币越多，成功率越低。

Tips: 失败不降级 失败只损失这次的锻造锤和金币，等级保持不变。 👀️

武器强化提升攻击伤害；护甲强化提升物理防御，以及护甲附带的攻击和生命。增加的部分在 lore 里用绿色括号显示，例如 `53.5 (+32.1)`。

## 重铸与特殊材料

**装备重铸**：花费金币、材料和一段时间，重新随机装备的基础属性。所需材料一般是锻造材料的一半左右。建议在大量**强化之前**重铸。

**特殊材料**：锻造材料、锻造锤等都在这里制作。制作同样排队计时；中途取消会退还未完成批次的材料和金币。

## 属性、套装与防御

常见属性：攻击伤害、暴击率、暴击伤害、攻击速度、物理防御、生命值。部分装备带宝石槽。

| 套装   | 四件套效果            |
| ------ | --------------------- |
| 黑曜石 | 生命 +6，打怪伤害 +3% |
| 地牢   | 生命 +8，打怪伤害 +4% |

## 灵魂绑定

绑定后，最后一行显示「灵魂绑定：玩家名」。

* **何时绑定**：从铁匠 NPC 领取时绑定给领取人；旧装备第一次拿在主手或穿上时绑定。
* **不能丢弃**：Q 键丢出、拖出背包都会被拦下，但可以放进箱子。
* **别人用不了**：其他玩家拿到后不能攻击、射箭、挖掘、穿戴，也不能强化或重铸。

## 星级锻造

装备强化到 +30 后，开始星级锻造。星锻和 +N 强化互不影响。

* **门槛**：装备必须先达到 +30。
* **星级**：每件装备 5 颗星，每次成功点亮 ¼ 颗。
* **专用锤子**：星锻锤和铁匠铺的锻造锤是两种物品，不能混用。
* **加成显示**：星级攻击加成写在 RPG 攻击那一行的括号里。

可以右键打开委托菜单，完成每日、每周委托获取奖励。

## 常见问题

**强化失败会掉级吗？** 不会，只消耗锤子和金币。

**工具能强化吗？** 不能，镐、铲、锄没有战斗属性。

**星级锻造放不进装备？** 先确认装备已经 +30，再确认用的是星锻锤。

**绑定装备被朋友拿走了？** 别人用不了，找对方要回即可。
