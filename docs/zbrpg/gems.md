# 💎 宝石系统

宝石可以镶嵌在 RPG 装备的**宝石槽**里，为装备额外增加属性。宝石共 **5 种**，每种 **1 \~ VII 级**，等级越高加成越多。同等级的宝石可以**突破**成更高一级的宝石。

> 装备有几个宝石槽，就能镶几颗宝石。同一件装备可以镶**多颗同种宝石**，效果叠加。

---

## 宝石种类

| 宝石                     | 增加属性     | 可镶嵌在             |
| ------------------------ | ------------ | -------------------- |
| 🔴**力量宝石**     | 攻击伤害     | 近战武器 / 弓 / 护甲 |
| 🔵**防御宝石**     | 物理防御     | 近战武器 / 弓 / 护甲 |
| 🟢**生命宝石**     | 额外生命     | 近战武器 / 弓 / 护甲 |
| 🟠**暴击宝石**     | 额外暴击伤害 | 近战武器 / 弓        |
| 🟣**暴击概率宝石** | 暴击概率     | 近战武器 / 弓        |

### 各等级数值

每颗宝石的数值是在下面的**区间里随机**生成的，同等级的宝石数值也会有高有低，装备说明里显示到小数点后一位。

| 等级 | 力量       | 防御      | 生命      | 暴击伤害      | 暴击概率    |
| ---- | ---------- | --------- | --------- | ------------- | ----------- |
| I    | 0.8\~ 1.2  | 0.8\~ 1.2 | 0.8\~ 1.2 | 2.4%\~ 3.6%   | 0.4%\~ 0.6% |
| II   | 1.6\~ 2.4  | 1.6\~ 2.4 | 1.6\~ 2.4 | 4%\~ 6%       | 0.8%\~ 1.2% |
| III  | 2.8\~ 4.2  | 2.4\~ 3.6 | 2.4\~ 3.6 | 6.4%\~ 9.6%   | 1.2%\~ 1.8% |
| IV   | 4\~ 6      | 3.6\~ 5.4 | 3.2\~ 4.8 | 9.6%\~ 14.4%  | 2%\~ 3%     |
| V    | 5.6\~ 8.4  | 4.8\~ 7.2 | 4.8\~ 7.2 | 12.8%\~ 19.2% | 2.8%\~ 4.2% |
| VI   | 7.6\~ 11.4 | 6.4\~ 9.6 | 6.4\~ 9.6 | 17.6%\~ 26.4% | 4%\~ 6%     |
| VII  | 9.6\~ 14.4 | 8\~ 12    | 8\~ 12    | 24%\~ 36%     | 5.6%\~ 8.4% |

> 💡 因为每颗宝石的数值都不同，宝石**不能叠在一起**，一颗占一格。拆下来的宝石数值不变；突破出来的新宝石会在新等级的区间里重新随机。

---

## 宝石在什么时候生效

* **武器上的宝石**：武器**拿在主手**时生效。 武器上也可以镶防御宝石和生命宝石，拿在手上就会加防御 / 生命。
* **护甲上的宝石**：护甲**穿在身上**时生效。
* 弓上的力量宝石会加到射出的箭的伤害上。

### 在装备说明里怎么看

镶嵌后，装备说明里会多出一行宝石信息，例如：

```
◆ 力量宝石 V  攻击伤害 +7.0
```

同时，宝石的加成会**直接写进对应属性后面的括号里**。比如一把武器原本是：

```
⚔ 攻击伤害 29.8 (+4.5)
```

镶上一颗 **力量宝石 V（+7.0）** 后会变成：

```
⚔ 攻击伤害 29.8 (+11.5)
```

## 🔨 镶嵌宝石

1. 打开背包。
2. 用鼠标**拿起宝石**。
3. **点击要镶嵌的装备**。

宝石会自动嵌进装备的**第一个空宝石槽**。

> ⚠️ 以下情况无法镶嵌：
>
> * 装备的宝石槽已经满了
> * 这种宝石不能镶在这类装备上（例如暴击宝石不能镶在护甲上）
> * 不是 RPG 装备，或者装备不属于你

---

## ⛏️ 拆卸宝石

宝石**只能在宝石匠 NPC 处拆卸**，需要准备 **拆宝石锤**。

1. 找到 **宝石匠** NPC，右键打开拆卸界面。
2. 点击背包里的装备，把它放到中间的台座上。
3. 下方一排显示装备的所有宝石槽，**点击要拆下的宝石**。
4. 拆完后点击中间的装备即可取回。

* 每拆一颗宝石消耗 **1 把拆宝石锤**（锤子是一次性的）。
* 拆下的宝石**完整退回**，等级和数值都不变。
* 背包满了的话，宝石会掉在脚下。

## ✨ 宝石突破

把**同等级**的宝石合成一颗**更高一级**的宝石。

**打开方式：** 输入 `/gem`

1. 点击背包里的宝石，放进下方 5 个格子（点击格子里的宝石可以取回）。
2. 左边会显示当前成功率和可能得到的宝石。
3. 点击中间的 **✔ 绿色按钮** 开始突破。

### 成功率

| 放入数量   | 成功率         | 失败时            |
| ---------- | -------------- | ----------------- |
| 5 颗       | **100%** | —                |
| 4 颗       | **50%**  | 随机退回 1\~ 2 颗 |
| 3 颗及以下 | 无法突破       | —                |

> ⚠️ 只能放**同一等级**的宝石；**VII 级**是最高等级，不能再突破。

### 突破出哪种宝石？

可以放入**不同种类**的宝石。突破出来的种类**按放入的数量比例随机**。

**例：** 放入 2 颗力量宝石 III + 3 颗防御宝石 III

| 结果        | 概率 |
| ----------- | ---- |
| 力量宝石 IV | 40%  |
| 防御宝石 IV | 60%  |

想要指定种类，就放 5 颗同种宝石，必定得到那一种。

## 常见问题

**Q：同一件武器能镶好几颗力量宝石吗？** 可以，同种宝石的加成会叠加。

**Q：拆宝石会损坏宝石吗？** 不会，宝石完整退回，只消耗 1 把拆宝石锤。

**Q：突破界面里放了宝石，关掉界面会丢吗？** 不会。宝石一直留在你的背包里，只有点下突破按钮的那一刻才会扣除。

**Q：防御宝石镶在武器上有用吗？** 有用，武器拿在主手时生效。
