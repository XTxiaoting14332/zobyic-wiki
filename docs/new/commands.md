为了让新人更快上手，这里把**日常最常用**的插件和指令都放在了一页里。不用全背下来，收藏这页，用到了再翻 📌

## “😳 啥是插件服？”

> “这服要装 mod 吗？”
>
> “为什么菜单、装备都长得和原版不一样？”

Zobyic Realms 是**插件服**：新玩法都是服务器上的插件做的，新物品和界面靠资源包显示。所以你<span style="color:#e8590c">用原版客户端就能玩</span>，进服点接受资源包就行 👉 [资源包加载](/new/resourcepack)

| 对比             | 插件服（我们）         | mod 服                   |
| ---------------- | ---------------------- | ------------------------ |
| 客户端要装东西吗 | ✅ 不用，原版直接进    | ❌ 必须装服务器的 mod 包 |
| 能用多个版本吗   | ✅ 1.21.4～26.1 都能进 | ❌ 基本只能一个版本      |
| 流畅度           | ✅ 流畅                | ❌ 比较吃配置            |
| 新物品哪来的     | 插件 + 资源包          | mod                      |

## 📋 主菜单

服务器的大部分功能都能从 **主菜单** 进去，不记得指令就先开菜单找找。

| 操作                      | 作用       |
| ------------------------- | ---------- |
| `/menu /cd 或者shift+f` | 打开主菜单 |

主菜单里可以选择世界（生存、资源）、打开各种功能。从菜单进生存或资源世界时，会**回到你上次下线的位置** 😎


## 🏠 领地（Residence）

圈了领地，别人就动不了你的方块和箱子。**圈地工具是木锄** 🪓

### 怎么圈地

1. 手拿 **木锄**，**左键** 点领地的一个角
2. **右键** 点对角的另一个角
3. 输入 `/res create 领地名` 创建领地

> “我只圈了地面，地下的矿被别人挖了？”

选好两个点之后，先输入 `/res select vert`，把选区从地底一直扩到天空，再创建就不怕了 👍

### 常用领地指令

| 指令                                        | 作用                                         |
| ------------------------------------------- | -------------------------------------------- |
| `/res create 领地名`                      | 用选好的区域创建领地                         |
| `/res select vert`                        | 把选区上下拉满（从基岩到天空）               |
| `/res info`                               | 查看脚下这块领地的信息                       |
| `/res list`                               | 查看自己有哪些领地                           |
| `/res tp 领地名`                          | 传送到自己的领地                             |
| `/res tpset`                              | 把领地的传送点设在你站的位置                 |
| `/res padd 领地名 玩家名`                 | 把朋友加进领地，让他也能建造、开箱子         |
| `/res pset 领地名 玩家名 权限 true/false` | 单独给某个玩家开 / 关某项权限                |
| `/res set 领地名 权限 true/false`         | 设置领地对所有人的权限，比如禁止别人进入     |
| `/res kick 玩家名`                        | 把某个玩家踢出你的领地                       |
| `/res remove 领地名`                      | 删除领地（会让你输入 `/res confirm` 确认） |

## 💰 金币与交易

| 指令              | 作用                                 |
| ----------------- | ------------------------------------ |
| `/balance`      | 查看自己有多少金币                   |
| `/trade 玩家名` | 和其他玩家发起交易，双方确认后才成交 |

交易只用 **金币** 结算，所有人都收 **5% 手续费**。

::: danger 禁止私下交易
不许用现实里的钱（转账、红包、Q 币等）买卖金币、装备、账号，买卖双方都会被处罚 👉 [服务器规则](/new/rules)
:::
