# 新手教程

欢迎来到 Zobyic Realms。跟着这一页走完新手引导，大约十几分钟就能开始你的旅程。

## 进服之前

::: warning 客户端版本
服务器只支持 **1.21.4 及以上** 的客户端，版本太旧会被提示升级后才能进入。
:::

进服时会自动下发和你的版本匹配的资源包，请选择**接受**，否则会看不到装备、菜单和宠物的贴图。

## 登录

每次进服都会弹出一个输入框：

1. 第一次进服时设置你的密码，请记牢。
2. 之后每次进服，在输入框里输入密码登录。

没有登录就无法进入服务器。密码不要告诉任何人。

## 新手引导

找到主城的 **新手引导 NPC**，右键开始。按顺序完成下面几步：

1. **观看介绍短片**：右键新手引导 NPC，了解服务器。
2. **前往生存世界**：打开菜单，选择生存世界，随机传送到野外。
3. **砍树做锄头**：砍些木头，合成一把**木锄**。
4. **圈一块领地**：拿着木锄，左键点一个角，右键点对角，再输入 `/res create 领地名`。
5. **下矿**：前往资源世界，挖到 **16 个铜矿** 和 **16 个铁矿**。
6. **开始旅程**：完成后新手引导结束。

::: tip 为什么要圈领地
圈好的领地只有你能破坏和使用，别人动不了你的方块和箱子。以后建家、种田都在领地里进行。
:::

## 各个世界

| 世界            | 用途                                 |
| --------------- | ------------------------------------ |
| 主城            | 出生点、传送、各种 NPC 和功能建筑    |
| 生存 1 / 生存 2 | 建家、圈地、长期生活（含下界和末地） |
| 资源 1 / 资源 2 | 挖矿、砍树、探索遗迹，不适合建家     |
| 宝库猎人        | 避难所、荒原等特殊区域               |

info 自动回到上次的位置
从主城菜单进入生存或资源世界时，会回到你上次在那里下线的位置，不用每次重新找路。

## 接下来玩什么

- **冒险等级**：屏幕左侧显示你的冒险等级，所有人从 0 级开始。
- **RPG 装备**：右键主城的铁匠 NPC 打造和强化装备，详见 [RPG 玩法教程](/rpg)。
- **遗迹与 BOSS**：资源世界里有遗迹，去探索并打造更好的装备！
- **钓鱼**：收集鱼类图鉴，参加钓鱼大赛赢钓鱼币。
- **农业**（即将开放）：在领地里开田种作物。
- **宠物**：带一只宠物陪你冒险，它会给一些小加成。
- **交易**：用 `/trade` 和其他玩家交易，只用金币结算，收取 5% 手续费。
