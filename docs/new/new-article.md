# 🧭 新手教程

::: info
刚落地 Zobyic Realms，有点懵？别慌，跟着这页走一遍，十几分钟就能开始你的旅程 🚀
:::

## “🤔 进服前要准备啥？”

> “我是 1.20 的客户端，能进吗？”
>
> “怎么进来以后装备全是紫黑格子？？”

这两个问题<span style="color:#e8590c">很很</span>常见，一次说清楚：

| 要准备的   | 说明                                                                           |
| ---------- | ------------------------------------------------------------------------------ |
| 客户端版本 | ✅**1.21.4 及以上** 都能进 ❌ 版本太旧会被提示升级                       |
| 资源包     | 进服时自动下发，记得点**接受**。不接受的话装备、菜单、宠物贴图全都看不到 |
| 装 mod 吗  | ❌ 不需要，原版客户端直接进                                                    |

每次进服都会弹出一个输入框：

1. **第一次进服**：设置一个密码，请记牢 ~~忘了别来哭~~

不要把密码告诉任何人，包括自称管理员的人。管理员**永远不会**向你要密码。
:::

## “📋 新手引导怎么做？”

找到主城的 **新手引导 NPC**，右键开始。一共 7 步，按顺序来：

1. 🎬 **观看介绍短片**：右键新手引导 NPC，了解一下服务器
2. 🌲 **前往生存世界**：打开菜单选生存世界，随机传送到野外
3. 🪓 **砍树做锄头**：砍点木头，合成一把 **木锄**
4. 🏠 **圈一块领地**：拿着木锄，左键点一个角，右键点对角，再输入 `/res create 领地名`
5. ⛏️ **下矿**：去资源世界，挖到 **16 个铜矿** 和 **16 个铁矿**
6. 🎉 **开始旅程**：完成！新手引导结束

> “为什么一定要圈地啊？”

因为圈好的领地**只有你**能破坏和使用，别人动不了你的方块和箱子。以后建家、种田都在领地里进行 <span style="color:#d63a3a;font-size:13px">（不圈地被偷了可别找管理哦）</span>

## “🗺️ 这么多世界，去哪个？”

| 世界            | 适合干嘛                             | 能建家吗  |
| --------------- | ------------------------------------ | --------- |
| 主城            | 出生点、传送、各种 NPC               | ❌        |
| 生存 1 / 生存 2 | 建家、圈地、长期生活（含下界和末地） | ✅        |
| 资源 1 / 资源 2 | 挖矿、砍树、探索遗迹                 | ❌ 不适合 |
| 宝库猎人        | 避难所、荒原等特殊区域               | —        |

😏 小贴士：从主城菜单进生存或资源世界时，会**回到你上次下线的位置**，不用每次重新找路。

## “🎮 新手引导做完了，然后呢？”

| 玩法             | 一句话介绍                                                               |
| ---------------- | ------------------------------------------------------------------------ |
| 📈 冒险等级      | 屏幕左侧显示你的冒险等级，大家都从 0 级开始                              |
| ⚒️ RPG 装备    | 右键主城的铁匠 NPC 打造、强化装备 👉[RPG 玩法总览](/zbrpg/rpg-overview)     |
| 🏛️ 遗迹与 BOSS | 资源世界里有遗迹，开始你的探险                                           |
| 🎣 钓鱼          | 收集鱼类图鉴，参加每周钓鱼大赛赢钓鱼币                                   |
| 🌾 农业          | 开田种作物<span style="color:#d63a3a;font-size:13px">（即将开放）</span> |
| 🐾 宠物          | 带一只宠物陪你冒险，还有一些小加成                                       |
| 🤝 交易          | `/trade` 和其他玩家交易，只用金币结算，收 5% 手续费                    |
