# 🖥️ 客户端选择

进服之前先选个客户端。用群里的端最省事，想自己组端也完全可以，这页把两种方式都讲清楚 👇

---

## “🤔 我该用哪个版本？”

> “我是 1.20 的，能进吗？”
>
> “听说新版本出了，最新版能进吗？”

| 版本                   | 能进吗                                                        |
| ---------------------- | ------------------------------------------------------------- |
| 1.21.4 以下            | ❌ 进不了，会提示你升级                                       |
| **1.21.4～26.1** | ✅ 都能进                                                     |
| ⭐**1.21.8**     | ✅<span style="color:#e8590c">推荐</span>，和服务器版本最贴合 |

😏 版本不对的话，进服时会直接提示你，不用自己瞎猜。

---

| 对比     | 群里的端                              | 自己组端               |

> “我啥都不懂，直接玩行不行？”

行！去群文件下载群里的端，解压打开就能进服 🚀

---

## “🔧 自己组端要注意啥？”

1. 版本选 **1.21.8**（1.21.4～26.1 之间都行）
2. 原版客户端就能进，**不装 mod 也能正常玩**
3. 进服时会自动下发资源包，记得点 **接受**，不然装备、菜单、宠物贴图都看不到

---

## “🚫 什么不能装？”

danger 禁止外挂类客户端和 mod
**不要带任何外挂类型的东西进服！** 一经发现会被处罚 ~~别问，问就是封~~


下面这些都算外挂类，<span style="color:#d63a3a">一律禁止</span>：

| 类型          | 举例                       |
| ------------- | -------------------------- |
| ❌ 透视类     | 矿物透视、看穿墙壁         |
| ❌ 战斗辅助   | 杀戮光环、自动瞄准、连点器 |
| ❌ 移动作弊   | 飞行、加速、穿墙           |
| ❌ 外挂客户端 | 各类整合了作弊功能的“端” |

> “那我装个优化 mod 让游戏不卡，算外挂吗？”

不算 👌 只要不给你带来不公平的优势就没问题。拿不准的话，先在群里问一下管理再装。

---

## “🆘 进不去服怎么办？”

先检查版本是不是在 **1.21.4～26.1** 之间，再看资源包有没有点接受。还是不行就到 QQ 群 **140350955** 里问 🥰
