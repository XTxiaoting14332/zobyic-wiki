# 📜 服务器规则

::: info
进服即视为同意本规则。规则是给大家一个公平、舒服的游戏环境，不是为了为难谁 🤝 看完再玩，少踩坑！
:::

- 本规则由 **腐竹和管理组** 共同执行，是处理问题时的<span style="color:#e8590c">参考依据</span>，管理组会结合实际情况判断，不是死板地照条文套。
- 规则里没写到的行为，只要明显破坏公平或影响他人，管理组同样有权处理。
- 处罚针对的是**账号**和**行为**。<span style="color:#d63a3a">「号借给朋友了」「是我弟玩的」「被盗号了」这类说法不能用来免除处罚</span>，账号的安全由你自己负责。
- 被封禁后可以换个账号重新开始，但 **用新号逃避处罚、继续违规** 会被直接永久封禁。
- 本规则的最终解释权归 Zobyic Realms 运营团队所有，规则更新后以本页为准。

---

## 一、作弊与外挂

### 1. 使用外挂客户端或作弊功能

- 包括但不限于：杀戮光环、自动瞄准、连点器、飞行、加速、穿墙、无击退、变速齿轮等。
- 情节一般：封禁 **3 天～3 个月**；情节恶劣或屡犯：**永久封禁**。

### 2. 使用透视类作弊

- 包括矿物透视材质包、透视 mod、能看穿方块的光影或设置等。
- 第一次：封禁 **7 天**，并清理透视期间获得的矿物。
- 第二次：**永久封禁**。
- 获利巨大的，核实后直接 **永久封禁**。

### 3. 使用自动化脚本

以下脚本一经核实，处以 **7 天～永久封禁**，并可能 **清零相关游戏资产**：

| 类型        | 举例                               |
| ----------- | ---------------------------------- |
| ❌ 自动挖矿 | 自动寻矿、自动挖掘及各种变种       |
| ❌ 自动钓鱼 | 挂机钓鱼脚本、钓鱼大赛期间的自动化 |
| ❌ 自动农业 | 自动种植、自动收割脚本             |
| ❌ 自动刷取 | 自动强化、自动刷怪、自动刷委托     |

不影响游戏平衡、也不用来获利的辅助工具（比如优化类 mod），默认允许。拿不准就先问管理。

### 4. 利用漏洞（BUG）

- 包括复制物品、刷金币、刷强化、卡出权限、绕过领地保护等。
- 一经确认：**永久封禁**，并回收所有相关资产。
- 知道别人在刷 BUG 不举报，还和他交易、帮他藏东西的，按 **同伙** 处理，涉事资产一律回收。

::: tip 发现 BUG 怎么办？
第一时间私聊管理或在 QQ 群上报。**主动上报的不会受罚**，但上报前用它获利的部分会被回收。
:::

### 5. 公开宣传作弊

- 在公屏、群里炫耀作弊、教别人作弊、挑衅管理的，视为 **主动违反规则**，按言行和实际情况处罚。

## 二、账号与小号

> “我能开小号吗？”

可以开，但 <span style="color:#e8590c">**小号不能用来获利**</span>。小号只能当作独立的号自己玩，下面这些都算违规：

| 违规行为        | 说明                                                     |
| --------------- | -------------------------------------------------------- |
| ❌ 小号刷奖励   | 用小号重复领新手奖励、签到、在线奖励、委托奖励、活动奖励 |
| ❌ 小号输送资源 | 用小号挖矿、刷钱、做任务，再把东西或金币转给大号         |
| ❌ 小号刷比赛   | 用小号参加钓鱼大赛等活动，帮大号拿名次或奖励             |
| ❌ 小号刷交易   | 大小号互相交易，刷流水、躲手续费、转移被处罚的资产       |
| ❌ 小号占资源   | 用小号圈大片领地、占用公共资源                           |
| ❌ 小号逃避处罚 | 大号被封后用小号继续玩、继续违规                         |

**处罚：**

- 首次：回收所有通过小号获得的收益，小号封禁。
- 再次或数额较大：大号一并处罚，封禁 **7 天～永久**。

### 其他账号规定

- ❌ 禁止用现实货币买卖账号、金币、装备，详见下方「禁止私下交易」。
- ❌ 禁止冒充管理员、冒充其他玩家骗取物品或密码。
- 共用一个账号、把号借给别人玩出现的违规，**由账号本身承担**。

## 三、言论与社区

### 1. 禁止发布违规言论

- 包括但不限于：涉政、反国家、反社会、色情、血腥暴力、宣传其他服务器、辱骂开发者和管理组。
- 一经核实：**永久封禁**；情节特别恶劣的，列入服务器 **黑名单**。

### 2. 禁止人身攻击与骚扰

- 包括辱骂、地域黑、恶意刷屏、持续骚扰某个玩家、开盒或泄露他人隐私。
- 视情节处以 **警告、禁言、封禁**；泄露他人隐私的直接 **永久封禁**。

### 3. 禁止发布广告

- 包括其他服务器的广告、代练、收购账号、出售外挂等。
- 处以 **禁言** 或 **封禁**，屡犯永久封禁。

## 四、游戏环境与秩序

任何破坏服务器秩序的行为，视情节处以 **警告、禁言、扣除金币、临时或永久封禁**。包括：

| 类型              | 具体行为                                                                   |
| ----------------- | -------------------------------------------------------------------------- |
| 🖥️ 卡服         | 建造高频红石、超大刷怪塔、大量实体堆积、无限漏斗等严重影响服务器性能的装置 |
| 🏚️ 破坏他人建筑 | 恶意破坏、偷窃别人的东西，**没圈地的建筑也不行**                     |
| 🔥 恶意破坏地形   | 主城、公共区域乱挖乱放、放火、放岩浆                                       |
| ⚔️ 恶意 PK      | 在非 PVP 区域反复骚扰、诱杀其他玩家                                        |
| 🪤 恶意陷阱       | 在公共区域、领地门口设陷阱坑人                                             |
| 💰 交易诈骗       | 承诺交易后不给东西、调包、骗钱                                             |
| 📉 扰乱市场       | 恶意垄断、哄抬价格、利用规则漏洞套利                                       |

### 禁止私下交易

> “我们俩在 QQ 说好了，我给他现金，他再给我游戏币，不行吗？”

<span style="color:#d63a3a">**不行！**</span> 只要涉及**现实里的钱**，就算私下交易，一律禁止。

| 算私下交易 ❌    | 说明                                         |
| ---------------- | -------------------------------------------- |
| 现金换游戏币     | 微信、支付宝转账，发红包，换金币             |
| 现金买装备、物品 | 花钱买别人的强化装备、星锻装备、材料等       |
| 买卖账号         | 出售或收购游戏账号                           |
| 代练、代刷       | 收钱帮别人练级、强化、刷委托、钓鱼大赛冲名次 |
| 用其他东西抵钱   | Q 币、点卡、游戏皮肤、其他游戏的道具等       |

不管是在 QQ、微信还是别的地方谈的，只要用现实的钱或东西换服务器里的东西，都算。

**处罚（买卖双方都罚）：**

- 首次：回收交易涉及的金币、物品，双方封禁 **7 天**。
- 再次，或者交易金额较大：**永久封禁**。
- 长期倒卖、以此牟利的卖家：直接 **永久封禁**，相关账号全部处理。

::: warning 私下交易被骗，管理组不处理
私下交易本身就违规，钱付了没收到东西、东西给了钱没到账，管理组都 **不会帮你追回** ~~还会顺手把你一起罚了~~
:::

游戏里玩家之间用金币买卖东西，请用 `/trade` 完成。想支持服务器，请走官方的赞助渠道。

## 五、处罚复查与申诉

1. 觉得处罚有误，可以在 **处罚后 7 天内** 到 QQ 群 **140350955** 联系腐竹申诉，最晚不超过 **30 天**，超时视为放弃。
2. 申诉时请说清楚账号、被处罚的时间和理由，并提供能证明自己的材料（截图、录屏、游戏日志等）。
3. 反作弊系统和管理人工审查都认定为作弊的，仍然可以提交证据申请复查；但如果证据被发现 **有修改痕迹**，直接驳回，并 **加重处罚**。
4. 申诉期间如果还在违规，按情节加重处罚。
5. 处罚后态度恶劣、辱骂管理的，可以从重处罚。

## 六、管理组权限说明

1. 管理员是规则的执行者，按照本规则对违规玩家进行处罚。
2. 管理员 **不能私自解封** 被封禁的玩家，误封请向腐竹申请解封。
3. 管理员 **不能干扰** 正常玩家的游戏，不能利用权限给自己或朋友谋利。
4. 涉及管理员本人的纠纷，管理员不能亲自处罚对方，需交给其他管理或腐竹处理；对方恶意挑事的除外。
5. 管理员处罚玩家时，需要说明对方违反了哪一条规则。
6. 管理员的权限由腐竹直接授予，**不能转交** 给其他玩家。
7. 管理员违反规则，由腐竹 **从重处理**。

::: tip 发现管理员滥用权限？
直接到 QQ 群 **140350955** 找腐竹反馈，带上截图或录屏 📸
:::
