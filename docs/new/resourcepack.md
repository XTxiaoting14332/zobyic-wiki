# 🎨 资源包加载


服务器的装备、菜单、宠物、家具全靠资源包显示。进服时会自动下载，这页讲讲加载时可能遇到的情况，<span style="color:#e8590c">别着急</span>，基本都能解决 😌

## “📥 进服弹出个提示，点啥？”

> “进服的时候跳出一个框问我要不要下载资源包……”

点 **接受** / **是** 就对了 ✅

服务器会自动给你发和你版本匹配的资源包，不用自己去找、也不用手动安装。

| 选择    | 结果                                         |
| ------- | -------------------------------------------- |
| ✅ 接受 | 正常显示所有装备、菜单、宠物贴图             |
| ❌ 拒绝 | 东西全是紫黑格子或者原版样子，菜单也看不明白 |

---

## “⏳ 怎么一直在加载？”

> “进度条卡着不动，是不是坏了？？”

<span style="color:#e8590c">先别急！</span> 资源包里东西比较多，**第一次下载**会慢一些，网不好的时候更久，耐心等一会儿 🍵

下载过一次以后会缓存在本地，之后再进服就快多了 ~~第一次的等待是值得的~~

---

## “😵 加载失败 / 贴图不对，怎么办？”

按顺序试试下面几招，大部分情况第 1、2 步就好了：

1. 🔄 **退出重进**：直接断开，再重新进一次服务器，最有效的一招
2. ⚙️ **检查服务器设置**：多人游戏列表里选中服务器 → 点「编辑」→ 把「服务器资源包」改成 **启用** 或 **提示**，别选「禁用」
3. 🧹 **关掉自己的资源包**：如果你自己还开着别的材质包，先关掉，有时会和服务器的冲突
4. 🔁 **重启游戏**：彻底关掉游戏再打开，然后进服
5. 🆘 **去群里问**：还是不行就到 QQ 群 **140350955** 里说一下你的情况，大家会帮你看 🥰

::: tip 问的时候带上这些，解决更快
你的游戏版本、用的是群里的端还是自己组的端、出问题时的截图 📸
:::

---

## “🤔 怎么知道资源包加载好了？”

进服后看看这几样，正常显示就说明没问题 👌

| 看哪里           | 正常的样子                         |
| ---------------- | ---------------------------------- |
| 打开菜单         | 有图案的功能图块，不是一堆普通物品 |
| 主城的家具和装饰 | 有自己的模型和贴图                 |
| 屏幕顶部         | 显示金币数之类的                   |

😏 如果看到紫黑格子，那就是资源包没加载上，回到上面一步步试就行。
