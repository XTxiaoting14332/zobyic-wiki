> Zobyic Realms 是基于 Minecraft Java 版 1.21.8 搭建的社区服务器，致力于为玩家提供稳定、友好的方块世界联机体验。
>

- Zobyic Realms 是一款运行于 Minecraft Java 版 1.21.8 的原创向多人服务器。我们不局限于原版生存，开发了**原创 RPG 体系、原创机械动力、宝库猎人特色玩法**，搭配丰富的武器系统、大世界遗迹 BOSS、精美时装与多元休闲内容。在这里，你既可以踏上史诗冒险，和朋友一起配合挑战强大的遗迹首领，制作强力装备，收集华丽外观打造专属于您的人物形象；也可以沉浸在机械创造之中，或是选择轻松休闲的游玩方式，休闲钓鱼轻松社交，在广阔世界中自由的探索。
