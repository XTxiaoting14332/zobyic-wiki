# 采矿

## 轻型钻井平台

![轻型钻井平台](/images/ztech/mining-drill.png)

1. 轻型钻井平台：放置于地面，自正下方逐层处理 3×3 范围
2. 电网：每处理一格耗电 20 RF

1. 放置于地面并接入电网；
2. 右键打开界面，在顶部的钻头槽放入【钻头】（由液压冲压机冲压钢板获得）；
3. 平台自正下方开始逐格处理下方 3×3 范围，每完成一层即下降一层，直至基岩。

- 每 1.5 秒处理一格，每格耗电 20 RF；钻头耐久为 250 格。
- 采得的矿物存入平台自身的库存，右键打开界面取出；库存已满时暂停工作。
- 可采得：粗铁、粗铜、粗金、煤炭、钻石、绿宝石、红石、青金石、下界石英、金粒、远古残骸。

::: warning 下方方块将被替换
平台处理过的每一格（基岩除外）均被替换为圆石；Y0 以下替换为深板岩圆石，下界中替换为下界岩。普通石头与泥土不进入库存，因此地面不会形成深坑；但下方原有的方块与建筑同样会被替换，请勿将平台放置于建筑或容器上方。
:::

## 重型地脉勘探开采平台

![重型地脉勘探开采平台](/images/ztech/geothermal-rig.png)

1. 重型地脉勘探开采平台：位于 5×5 区域正中心
2. 外圈 16 根铁栏杆：与平台同一高度，须完整闭合
3. 电网：持续耗电

重型地脉勘探开采平台是科技线的最终设备，不破坏任何方块，直接从地脉中勘探矿物：

- 平台位于中心，外圈 5×5 的边缘以 16 根铁栏杆完整围合，栏杆与平台位于同一高度；缺少任意一根时平台停机并报警。
- 接入电网后每 5 秒勘探一次，每次耗电 500 RF。
- 产物存入平台自身的库存，右键打开界面取出。

| 产物 | 概率 |
| :--- | :--- |
| 粗铁 3～6 | 20% |
| 粗金 2～4 | 15% |
| 粗铜 3～6 | 15% |
| 青金石 4～8 | 12% |
| 红石 4～8 | 10% |
| 钻石 1～2 | 9% |
| 绿宝石 1～2 | 8% |
| 下界石英 3～6 | 8% |
| 远古残骸 | 3% |

## 电动工具

手动采矿可使用电动钻。电动钻 III 可一次挖掘同一水平面上的多个同种方块，见 [电力](/ztech/energy-generators#电动工具)。
