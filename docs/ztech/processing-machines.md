# 加工机器

## 电力加工机

粉碎机、液压冲压机、拉丝机、搅拌器、动力锯、离心机、洗矿机、打包机、结晶器与窑均为电力加工机，使用方法相同：

1. 接入电网；
2. 右键打开界面；需要耗材的机器，先在耗材槽放入对应耗材；
3. 将材料放入输入槽，机器自动加工，产物保留在输出槽中，需手动取出。

普通加工机每 2.5 秒完成一件，结晶器的加工周期为普通机器的 5 倍。缺少耗材或材料、输出槽已满时，机器停止工作且不耗电。

| 机器 | 耗电 | 耗材 | 配方 |
| :--- | :--- | :--- | :--- |
| 粉碎机 | 4 RF/t | 研磨头 | 粗铁 / 铁矿石 → 2 铁粉；粗铜 / 铜矿石 → 2 铜粉；黑曜石 → 2 黑曜石粉；玫瑰石英 → 磨制玫瑰石英；圆石 → 砂砾；砂砾 → 沙子；花岗岩 / 红砂岩 → 红沙 |
| 液压冲压机 | 3 RF/t | 冲压模具 | 铁锭、铜锭、钢锭、青铜锭、黑钢锭 → 对应板材；钢板 → 钻头 |
| 拉丝机 | 2 RF/t | 无 | 1 铜板 → 2 铜线 |
| 搅拌器 | 5 RF/t | 搅拌叶片 | 1 铁粉 → 2 合金粉；1 铜粉 → 2 青铜粉 |
| 动力锯 | 3 RF/t | 锯片 | 1 原木 → 4 木板 |
| 离心机 | 8 RF/t | 高级电路板 | 铁粉 → 1 铁锭；铜粉 → 1 铜锭；洗净铁粉 → 2 铁锭；洗净铜粉 → 2 铜锭；2 红沙 → 1 红石 |
| 洗矿机 | 4 RF/t | 无；每件耗水 100 mB | 铁粉 → 洗净铁粉；铜粉 → 洗净铜粉；红沙 → 沙子 |
| 打包机 | 3 RF/t | 无 | 9 个 ↔ 1 块，自动判断方向 |
| 结晶器 | 6 RF/t | 无 | 洗净铁粉 → 铁晶体；洗净铜粉 → 铜晶体 |
| 窑 | 3 RF/t | 无 | 黏土球 → 红砖；沙子 / 红沙 → 玻璃；圆石 → 石头；深板岩圆石 → 深板岩；原木 → 木炭 |

补充说明：

- 耗材随使用磨损，耗尽后消失，需放入新的耗材。
- 洗矿机每次加工有 35% 概率产出副产物：清洗红沙时为红石，清洗矿粉时为燧石或黏土球。洗矿机的用水可由液体管送入，也可从相邻且有水的液体储罐自动补充，见 [流体](/ztech/fluid-networks)。
- 打包机支持的物品：铁锭、金锭、铜锭、煤炭、红石、青金石、钻石、绿宝石、粗铁、粗铜、小麦、黏液球、紫水晶碎片，以及各自对应的方块。

### 自动送料

原版漏斗无法向加工机送料，也无法从加工机抽取产物。粉碎机、液压冲压机、拉丝机、搅拌器、动力锯与离心机支持以下三种自动送料方式：

- 传送带末端正对机器，物品到达末端后进入输入槽；
- 溜槽自机器正上方向下送料；
- 机械臂将物品搬入机器。

如需产物同样自动流转，可采用下文的顶置加工。

## 顶置加工

![顶置加工](/images/ztech/inline-processing.png)

1. 粉碎机
2. 液压冲压机
3. 拉丝机
4. 动力锯
5. 储能方块：同时与支架和第一台机器相邻；相邻的加工机之间可相互传电
6. 发电机
7. 末端容器：加工完成的物品存入此处

将 **粉碎机、液压冲压机、拉丝机、动力锯** 置于传送带半砖正上方，物品从机器下方经过时立即完成加工，产物留在传送带上继续前进。传送带无需截断，多台机器可排列于同一条传送带上，组成连续产线。

- 机器内仍需装有耗材，每加工一件照常耗电并磨损耗材；
- 不符合该机器配方的物品原样通过；
- 仅上述四种电力加工机支持顶置加工。打包机、离心机等置于传送带上方时不工作，应力驱动的机械锯与机械压榨机亦不支持。

## 超频与散热

潜行时手持【超频芯片】右键加工机即可安装，每台最多安装 2 枚。

- 每枚芯片使加工速度提高 50%，耗电量按枚数倍增（1 枚为 2 倍，2 枚为 3 倍）。
- 超频机器每加工一件即产生热量，热度达到 100 时暂停工作，降温后恢复。无散热措施时，机器在工作过程中基本不会降温，因此会频繁暂停。

散热方式：

- **散热片**：潜行时手持散热片右键加工机安装，每台限装 1 片。安装后机器在工作过程中持续降温，过热后的恢复速度也更快。
- **冷却塔**：与加工机相邻放置，并以液体管供水。降温效果强于散热片，且可与散热片叠加。冷却塔每秒消耗 1 mB 水，最多储存 4000 mB，右键可查看水量。

![冷却塔](/images/ztech/cooling-tower.png)

1. 超频的加工机
2. 冷却塔：与加工机相邻放置
3. 液体管：为冷却塔供水

## 置物台

置物台是开放式工位，物品平放于台面上展示。

- 手持物品右键放置，空手右键取下；同种物品自动堆叠；
- 上方的漏斗或溜槽会自动向台面放入物品，下方的漏斗会自动抽取台面物品；
- 机械臂可将物品放置到置物台上。

![置物台冲压](/images/ztech/depot-press.png)

1. 置物台：手持物品右键放置
2. 机器与置物台之间可留空一格，也可直接相邻
3. 液压冲压机（电力）：位于置物台正上方 1～2 格内
4. 储能方块或电缆：为液压冲压机供电
5. 机械压榨机（应力）：同样位于置物台正上方 1～2 格内
6. 传动轴：接入应力网络

置物台正上方 1～2 格内放置以下机器时，会直接加工台面物品：

| 上方机器 | 效果 |
| :--- | :--- |
| 液压冲压机 / 机械压榨机 | 整组锭一次冲压为板材，无需装入冲压模具 |
| 动力锯 / 机械锯 | 整组原木一次锯为木板 |
| 注液器 | 对台面物品注液，见下文注液器 |

电力机器每次加工从电网取电一次，应力机器在网络运转时即可工作。置物台不能嵌入传送带中间使用，传送带上的物品也不会进入置物台。

## 部署器

部署器用于精密构件的序列装配。

![部署器](/images/ztech/deployer.png)

1. 部署器：位于传送带半砖侧面，与半砖同一高度，正面朝向半砖
2. 传送带另一侧亦可放置，按物品经过的顺序依次加工
3. 部署器由应力驱动
4. 传送带本身仍需通电

- 部署器由应力驱动，传送带照常耗电。正面未对准半砖时，可用扳手旋转朝向。
- 右键部署器放入本道工序所需的零件，工件经过时消耗 1 个零件。
- 部署器亦可置于置物台侧面，正面朝向置物台，加工台面上的工件。

精密构件的装配顺序为：**黄铜机壳 → 铜齿轮 → 铁板 → 铜齿轮 → 电子管**。黄铜机壳放上传送带后，依次经过装有上述零件的部署器，完成最后一道工序后成为精密构件；装配过程中的半成品为"未完成精密构件"。

## 注液器

![注液器](/images/ztech/spout.png)

1. 注液器：位于传送带半砖或置物台正上方
2. 液体管：连接注液器顶部或侧面
3. 抽水泵：需接入电网
4. 水源

注液器内部可储存 4000 mB 的水或岩浆，可通过液体管供给，也可手持水桶或岩浆桶右键直接注入。物品从下方经过，或位于下方 1～2 格的置物台上时，注液器对其注液：

| 液体 | 物品 | 产物 | 耗液量 |
| :--- | :--- | :--- | :--- |
| 水 | 玻璃瓶 | 水瓶 | 250 mB |
| 水 | 空桶 | 水桶 | 1000 mB |
| 水 | 泥土 / 砂土 | 泥巴 | 250 mB |
| 水 | 海绵 | 湿海绵 | 1000 mB |
| 岩浆 | 空桶 | 岩浆桶 | 1000 mB |

## 灌装机

灌装机外观为酿造台，需以液体管供水并接入电网（2 RF/t）。将空玻璃瓶或空桶放入酿造台的瓶槽后，自动灌装为水瓶（耗水 333 mB）或水桶（耗水 1000 mB）。

## 鼓风机

![鼓风机](/images/ztech/blower.png)

1. 鼓风机：朝放置时玩家面对的方向吹出 8 格气流，由应力驱动
2. 气流路径中有火、岩浆或岩浆块时：气流范围内的掉落物被烧炼
3. 另一台鼓风机
4. 气流路径中有水时：红沙与砂砾被淘洗为沙子

鼓风机向前吹出 8 格气流，可吹动气流范围内的掉落物与生物，遇到实心方块时气流终止。

- 气流路径中有火、岩浆或岩浆块时，范围内的掉落物被烧炼：粗铁、粗铜、粗金烧炼为锭，沙子与红沙烧炼为玻璃，圆石烧炼为石头，黏土球烧炼为红砖。
- 气流路径中有水时，红沙淘洗为沙子（35% 概率附带红石），砂砾淘洗为沙子（25% 概率附带燧石）。

鼓风机仅作用于地面上的掉落物，对传送带上的物品无效。朝向可用扳手旋转。
