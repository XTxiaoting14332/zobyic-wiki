# 传送带

## 基本搭建

![传送带](/images/ztech/belt-basic.png)

1. 起点支架
2. 传送带半砖（上半砖）
3. 终点支架
4. 起点支架后方的容器：传送带从中逐个取货
5. 终点外侧的容器：物品到达后自动存入
6. 电缆：连接任意一端的支架

- 两个支架位于同一高度、同一直线上，其间铺满传送带半砖（放置时自动成为上半砖），即构成一条传送带。
- 至少一端的支架需接入电网。断电时传送带停止，带上物品保持原位。
- 手持物品右键半砖可将物品放上传送带，空手右键半砖可取回物品。

| 支架 | 速度 | 耗电 |
| :--- | :--- | :--- |
| 传送带支架 | 约每秒 1 格 | 2 RF/t |
| 高速传送带支架 | 2 倍 | 6 RF/t |
| 极速传送带支架 | 4 倍 | 12 RF/t |

两端支架等级不同时，按较高等级计算。

### 方向

传送带的运输方向在连成线路时自动确定，与放置时玩家的朝向无关。空手右键支架可查看方向；方向有误时，手持扳手右键任意一端的支架，整条传送带随即反向，带上物品会掉落。

## 上货与卸货

**上货方式：**

- 起点支架后方放置容器，传送带自动从中逐个取货；
- 装载机从相邻容器向传送带送货；
- 溜槽底端正对半砖，物品直接落到传送带上；
- 手持物品右键半砖。

**卸货规则：** 物品到达终点支架外侧一格时，按该格的方块处理：

| 终点外侧方块 | 处理方式 |
| :--- | :--- |
| 箱子、木桶等容器 | 存入容器，无法存入的部分掉落 |
| 粉碎机、液压冲压机、拉丝机、搅拌器、动力锯、离心机 | 送入输入槽，输入槽已满时掉落 |
| 土制燃煤发电机、简易蒸汽机、蒸汽锅炉、生物燃油发电机 | 可燃物送入燃料槽，水桶送入水槽 |
| 另一条传送带的半砖 | 转入该传送带继续运输 |
| 倾斜传送带、滑轨、垂直传送带 | 转入该线路继续运输 |
| 卸载机 | 存入卸载机正面相邻的容器 |
| 其他 | 物品掉落在地面 |

自动合成器不接受传送带送料，其原料需放置于后方的容器中。

## 拐弯与合流

![拐弯](/images/ztech/belt-corner.png)

1. 第一条传送带的终点支架
2. 终点支架正前方的格子须为第二条传送带的半砖

第一条传送带的终点支架正对第二条传送带的任意一格半砖时，物品从该格转入第二条传送带。多条支线的终点支架正对同一条主线时，即构成合流。

## 装载机与卸载机

![装载机与卸载机](/images/ztech/loader-unloader.png)

1. 装载机：正面朝向半砖
2. 装载机后方的容器
3. 卸载机：位于终点支架外侧，正面朝向目标容器
4. 目标容器

- **装载机**：后方放置容器，正面朝向传送带半砖，每秒从容器中取出 4 个物品送上传送带。右键打开界面，前 5 格中放入的物品作为白名单，仅运输白名单内的物品；前 5 格为空时运输全部物品。
- **卸载机**：位于终点支架外侧，物品到达后存入其正面相邻的容器。
- 两者的朝向均可用扳手旋转。

## 传送带隧道

![传送带隧道](/images/ztech/tunnel.png)

1. 传送带隧道：覆盖于半砖正上方，该段运输速度提高至 1.5 倍

传送带隧道不耗电，可连续覆盖多格。

## 倾斜传送带

![倾斜传送带](/images/ztech/ramp-belt.png)

1. 水平传送带的终点支架
2. 倾斜传送带最下一级（驱动端）
3. 逐级向上铺设，至少 2 级
4. 顶端外侧可连接容器、传送带或机器
5. 上坡运输需供电，电源接于驱动端旁；下坡运输不耗电

倾斜传送带外观为石砖楼梯，用于向上或向下运输物品，无需支架：

- 每前进一格升高一格，逐级铺设，至少 2 级方可构成线路；楼梯朝向不影响连接。
- 最下一级为驱动端。上坡运输耗电 2 RF/t，电源接于驱动端旁；下坡运输不耗电。
- 手持扳手右键任意一级，可切换上坡与下坡。
- 入口：水平传送带终点外侧一格为楼梯时，物品自动转入；也可在传送带上方放置分流器，将物品分流至倾斜传送带。
- 出口：顶端同一高度外侧一格，可连接容器、传送带或机器。
- 右键楼梯可设置入口白名单。物品无法手动放置到倾斜传送带上。

## 滑轨

![滑轨](/images/ztech/slide-rail.png)

1. 滑轨第一级：紧邻传送带终点支架外侧
2. 逐级向下铺设，可转弯；物品仅能由高处滑向低处，不耗电
3. 底端外侧放置容器

滑轨外观为砂岩楼梯，物品仅能由高处滑向低处，运输速度快且不耗电，中途可转弯。自传送带终点外侧开始逐级向下铺设，并在底端外侧放置容器接收物品。右键滑轨可设置入口白名单。配合分流器，可将传送带上的指定物品分流至滑轨。

## 垂直传送带

![垂直传送带](/images/ztech/vertical-belt.png)

1. 水平传送带终点紧邻垂直传送带，物品自动转入
2. 垂直传送带：沿竖直方向叠放，自动连接为一列
3. 最下一节为驱动端
4. 顶端旁可连接容器、机器或传送带半砖
5. 驱动端旁接入电网：向上运输 2 RF/t，向下运输不耗电

- 沿竖直方向叠放，整列自动连通；任意高度均可从侧面接入水平传送带或装载机。
- 最下一节为驱动端，向上运输时需在其旁接入电网，耗电 2 RF/t；向下运输不耗电。
- 手持扳手右键任意一节，可切换向上或向下运输。
- 末端旁为加工机、蒸汽机、锅炉、传送带半砖或容器时，物品送入其中；无可接收的方块时物品掉落。

## 物品分流器

![物品分流器](/images/ztech/item-splitter.png)

1. 物品分流器：位于半砖正上方，正面朝向分流方向（可用扳手旋转）
2. 分流方向上紧邻的滑轨或倾斜传送带：白名单物品转入该线路
3. 滑轨末端的容器

- 物品分流器置于传送带半砖正上方。右键打开界面，手持物品点击前 5 格设置白名单（不消耗物品）；白名单为空时不分流。
- 白名单内的物品经过时，向分流器的朝向分出：该方向同高、低一格或高一格的位置存在滑轨或倾斜传送带时，物品转入该线路；否则物品被抛出并掉落在地面。
- 白名单外的物品沿传送带继续前进。
- 手持扳手右键可旋转分流方向。

::: tip 分流目标
物品分流器只能将物品交给滑轨或倾斜传送带。分流方向上为普通传送带时无法接收，物品会被抛出至地面。
:::

## 分拣机

![分拣机](/images/ztech/sorting-machine.png)

1. 分拣机：位于半砖正上方，可为前、后、左、右四个方向分别指定物品

右键打开界面，手持物品点击某一方向的格子，即指定该方向接收此种物品。匹配的物品从下方经过时，被抛向对应方向。手持扳手右键可清空全部设置。被抛出的物品为地面掉落物，需在落点设置漏斗或黄铜漏斗收集。

## 物品探测器与流量计

![探测器与流量计](/images/ztech/observer-flowmeter.png)

1. 物品探测器：贴于半砖侧面，检测到目标物品时输出红石信号
2. 由信号点亮的红石灯
3. 流量计：位于半砖正上方，右键可查看流量，有物品通过时输出红石信号

- **物品探测器**：外观为拉杆，贴于传送带半砖旁。手持物品右键设置检测目标，空手右键清除；未设置目标时检测任意物品。相邻传送带上出现目标物品时拉杆被拉下，输出红石信号。
- **流量计**：外观为比较器，置于半砖正上方。右键可查看累计通过数量与每分钟流量；最近 4 秒内有物品经过时输出红石信号。
