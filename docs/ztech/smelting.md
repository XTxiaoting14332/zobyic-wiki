# 冶炼

## 锻造炉与合金炉

![锻造炉与合金炉](/images/ztech/smeltery.png)

1. 锻造炉核心
2. 加热模块：贴于核心任意一面，每个使速度提高 50%
3. 电缆：需直接连接核心（加热模块不导电）
4. 合金炉核心：搭建方式与锻造炉相同

锻造炉与合金炉均由一个核心与若干加热模块组成，搭建规则相同：

- 加热模块贴于核心的上、下、东、南、西、北任意一面，至少需要 1 个，否则核心不工作；
- 每个加热模块使冶炼速度提高 50%，最多计入 6 个；
- 核心需接入电网。加热模块不导电，电缆或储能方块须与核心直接相邻；
- 右键核心打开界面；右键加热模块可查看所连核心的当前速度。

::: tip 预留一面
打开界面需右键核心，接入电网也需与核心相邻，因此实际使用时通常预留一面，最多贴 5 个加热模块。
:::

| 加热模块数量 | 速度倍率 | 每件耗时 |
| :--- | :--- | :--- |
| 1 | ×1.5 | 约 1.7 秒 |
| 2 | ×2 | 约 1.3 秒 |
| 3 | ×2.5 | 约 1 秒 |
| 4 | ×3 | 约 0.8 秒 |
| 5 | ×3.5 | 约 0.7 秒 |
| 6 | ×4 | 约 0.6 秒 |

### 锻造炉

- 解锁条件：机器累计加工 250 件。
- 耗电：6 RF/t。
- 可冶炼：粗铁、粗铜、粗金及对应矿石 → 锭；铁粉、铜粉 → 锭；合金粉 → 钢锭；青铜粉 → 青铜锭。

### 合金炉

- 解锁条件：机器累计加工 1000 件。
- 耗电：8 RF/t。
- 设有两个输入槽，分别放入两种矿粉：
  - 铁粉 + 铜粉 → 3 合金粉（产率高于搅拌器）
  - 铜粉 + 合金粉 → 2 青铜粉

## 高炉

![高炉](/images/ztech/blast-furnace.png)

1. 高炉
2. 顶部漏斗：送入粗矿
3. 侧面漏斗：送入燃料
4. 底部漏斗：抽出成品
5. 成品容器

高炉以燃料运转，无需电力：

- 可冶炼粗铁、粗铜、粗金及对应矿石，每件约 2.5 秒；
- 每次冶炼有 25% 概率额外产出 1 个锭；
- 可用燃料：煤炭、木炭、煤炭块、岩浆桶、烈焰棒、干海带块，以及原木、木板、木棍。

高炉支持与原版熔炉相同的漏斗自动化：顶部漏斗送入矿石，侧面漏斗送入燃料，底部漏斗抽出成品。

## 木炭窑

木炭窑外观为营火，无需电力与燃料。右键打开界面放入原木，每 10 秒烧制一根，产出 1 或 2 个木炭（平均 1.5 个），成品在界面中取出。木炭窑适合在缺少煤炭的早期阶段为燃煤发电机与蒸汽引擎提供燃料。

## 窑

窑是电力驱动的批量烧制机器，外观与其他加工机相同，为发射器。接入电网（3 RF/t）后右键打开界面放入材料，每 2.5 秒完成一件：

| 输入 | 产出 |
| :--- | :--- |
| 黏土球 | 红砖 |
| 沙子 / 红沙 | 玻璃 |
| 圆石 | 石头 |
| 深板岩圆石 | 深板岩 |
| 原木 | 木炭 |

窑可安装超频芯片与散热片，见 [加工机器](/ztech/processing-machines#超频与散热)。旧版窑的外观为烟熏炉，服务器重启后会自动替换为新外观，原有内容物掉落于窑旁。
