# 载具与升降

## 载具组装

![工程车](/images/ztech/vehicle-car.png)

1. 载具底盘：相邻的底盘连接为车架
2. 驾驶座：放置于底盘上
3. 发动机：放置于底盘上，每台载具限一个
4. 底盘正上方可放置箱子等普通方块作为货物

1. **铺设底盘**：以【载具底盘】（外观为平滑石）拼出车架，相邻的底盘自动连接为一体，也可向上叠加一层。
2. **放置驾驶座**：驾驶座放置于底盘上，或与底盘相邻。
3. **放置发动机**：在底盘上放置一个发动机，每台载具限一个。发动机类型决定载具类型。
4. **放置货物**（可选）：底盘正上方可放置箱子、木桶或装饰方块，随载具一同移动。
5. **登记**：手持工业扳手右键驾驶座，完成组装。结构变更后需重新登记。

单台载具最多包含 64 个方块。Z-Tech 机器方块、漏斗、发射器、投掷器、活塞、观察者、红石元件与铁轨无法装载于载具上。

### 发动机

| 发动机 | 载具类型 | 速度 | 每个煤炭行驶距离 |
| :--- | :--- | :--- | :--- |
| 车辆发动机 | 工程车，地面行驶 | 约每秒 6.7 格 | 约 160 格 |
| 船只发动机 | 机动船，水面行驶 | 每秒 5 格 | 约 266 格 |
| 航空发动机 | 飞艇，空中飞行 | 每秒 10 格 | 约 133 格 |

燃料仅限煤炭、木炭与煤炭块（1 个煤炭块相当于 10 个煤炭）。手持燃料右键发动机即可装入。

手持扳手潜行右键驾驶座可查看当前载具类型。更换载具类型需更换发动机并重新登记。

## 驾驶

- 空手右键驾驶座上车，潜行下车。
- 上车后载具自动朝玩家视线方向前进，无需按键。视线与当前方向的夹角超过 45° 时，载具转向至最接近的方向（东、南、西、北之一）。
- 前方受阻时载具停止，不消耗燃料；载具不会覆盖其他载具或 Z-Tech 机器方块。
- **工程车**：贴地行驶，前方为 1 格高的台阶时自动爬升；前方地面降低时随地形下降，每格最多下降 3 层。草、花等可穿过的方块会被车身压过。工程车无法驶入水域，前方为水或岩浆时停止。
- **机动船**：始终保持在水面高度行驶。
- **飞艇**：仰视超过 40° 时上升，俯视超过 40° 时下降，平视时保持高度。

![机动船](/images/ztech/vehicle-boat.png)

1. 底盘铺设于水面高度
2. 驾驶座
3. 船只发动机

::: tip 转向空间
载具转向时整体结构原地旋转。非对称结构需在周围预留足够空间，空间不足时会提示无法转向。
:::

## 气流升降机

![气流升降机](/images/ztech/elevator.png)

1. 气流升降机：右键产生持续 3 秒的上升气流，潜行右键产生下降气流；上方受阻时停止

气流升降机（外观为石英柱）放置于竖井底部。右键产生持续 3 秒的上升气流，潜行右键产生下降气流。上方被方块阻挡时停止。

## 滑轮电梯

![滑轮电梯](/images/ztech/rope-pulley.png)

1. 升降机滑轮：放置于井口
2. 绳索：自滑轮正下方逐格向下铺设，中间不得中断

1. 将升降机滑轮放置于井口顶部；
2. 手持绳索，自滑轮正下方开始逐格向下铺设至井底，中间不得中断；
3. 右键滑轮沿绳索上升，潜行右键下降。

破坏任意一节绳索时，其下方的绳索随之断开。
