# 载具与升降设备

Z-Tech 支持玩家使用底盘、发动机与驾驶座自由组装陆地、水面与空中载具，同时提供了矿井与多层建筑所需的垂直升降设备。

---

## 载具组装与使用流程

所有载具均由基础方块拼装后注册激活：

1. **拼接底盘**：使用【载具底盘】方块在地面或水面水平拼接，构成车架或船体结构；
2. **安装驾驶座与发动机**：在底盘上方放置【驾驶座】，并在相邻位置安装对应的【发动机】（每辆载具只需一个发动机）；
3. **注册载具**：手持工业扳手右键点击驾驶座完成注册；按住潜行键使用扳手右键驾驶座，可切换载具类型（工程车 / 机动船 / 飞艇）；
4. **添加燃料与驾驶**：右键点击发动机打开界面，放入煤炭、木炭或生物燃油等燃料；右键点击驾驶座上车，通过方向键（W/A/S/D）操控移动，按潜行键下车。

## 动力配件与发动机

### 1. 发动机性能对比

| 发动机名称 | 适配载具 | 制造原料 | 相对速度 | 燃油效率 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **车辆发动机** | 工程车 | 青铜板、活塞环、曲轴、黄铜机壳 | 中等 | 标准 | 适合陆地行进与爬坡 |
| **船只发动机** | 机动船 | 青铜板、推进螺旋桨、曲轴、黄铜机壳 | 稳定 | 较高 | 适合水面行驶，燃油消耗较慢 |
| **航空发动机** | 飞艇 | 涡轮叶片、曲轴、黄铜机壳 | 较快 | 较低 | 适合空中飞行，燃油消耗较快 |

### 2. 机械零部件

| 构件名称 | 制造材料 | 用途说明 |
| :--- | :--- | :--- |
| **载具底盘** | 铁锭、平滑石 | 载具骨架方块，水平相连构成车体或船体 |
| **驾驶座** | 深色橡木台阶、基础电路板 | 载具控制方块，用于注册结构与操控驾驶 |
| **活塞环** | 青铜锭 | 组装车辆发动机的零件 |
| **曲轴** | 传动轴、钢板 | 组装各类发动机的机械零件 |
| **推进螺旋桨** | 青铜板、青铜齿轮 | 组装船只发动机的零件 |
| **涡轮叶片** | 黑钢板、青铜齿轮 | 组装航空发动机的零件 |

## 常见载具搭建

### 1. 工程车
用于陆地行驶与物料转运：

![工程车示意图](/images/ztech/vehicle-car-assembly.png)

- **结构**：底部铺设载具底盘，上方放置驾驶座与车辆发动机；
- **驾驶**：右键驾驶座入座，操控方向键在陆地行驶。

---

## 2. 机动船
用于水面长距离航行：

![机动船示意图](/images/ztech/vehicle-boat-assembly.png)

- **结构**：水面铺设载具底盘，上方安装驾驶座与船只发动机；
- **驾驶**：在水面平稳滑行，燃料利用率较高。

---

## 3. 飞艇
用于空中跨越复杂地形：

![飞艇示意图](/images/ztech/vehicle-airship-assembly.png)

- **结构**：铺设载具底盘，上方安装驾驶座与航空发动机；
- **飞行操控**：驾驶飞艇时根据视线角度控制俯仰：
  - **抬头（仰角大于 40°）**：飞艇向上爬升；
  - **低头（俯角大于 40°）**：飞艇向下俯冲；
  - **平视**：保持当前高度水平飞行；
  - 按潜行键下艇。

## 垂直升降设施

用于深井与多层建筑的上下交通：

### 气流升降机
放置在垂直风道底部的单方块升降装置：

![气流升降机示意图](/images/ztech/elevator-shaft-setup.png)

- **上升**：右键点击升降机方块，底座会喷出持续 3 秒的向上气流，将玩家推至上方；
- **缓降**：潜行状态下右键点击升降机，会产生缓降气流，防止高空跌落伤害。

### 滑轮缆绳电梯
由升降机滑轮与垂直绳索构成的吊运系统：

![滑轮缆绳电梯示意图](/images/ztech/rope-pulley-elevator.png)

- **安装**：在天井顶部或底部放置【升降机滑轮】，使用【绳索】垂直直线铺设至另一端；
- **乘坐**：右键点击滑轮或绳索即可挂载并垂直移动；移动过程中右键可反转升降方向，按潜行键脱离。
