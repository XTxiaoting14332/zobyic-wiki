# Z-Tech 总览

Z-Tech 是服务器的科技玩法。玩家以电力和机械动力驱动机器，对矿石进行粉碎、冶炼、冲压、拉丝等加工，并通过传送带、机械臂等设备将各台机器连接为自动化产线。所有机器均以原版方块呈现，物品在传送带上的运输与加工过程直接可见，无需安装客户端模组。

## 入门物品

- **新手指南书**：4 个铁锭 + 1 本书（铁锭置于书的上、下、左、右）。右键打开后可查阅物品用途、摆放示意图与成就进度；首次打开即解锁科技线起点。
- **配方书**：1 本书 + 2 张纸。右键打开后可查阅全部 Z-Tech 物品的合成配方。

::: tip 配方以游戏内为准
本维基仅说明机器的搭建与使用方法，不逐条收录配方。配方书读取的是服务器当前实际注册的配方，具体配方请以配方书为准。
:::

## 三套系统

Z-Tech 的机器分属三套相互独立的网络。排查机器不运转的问题时，应首先确认该机器所属的系统。

| 系统 | 连接方式 | 典型机器 | 详见 |
| :--- | :--- | :--- | :--- |
| 电力 | 方块相邻，或以电缆连接 | 粉碎机、液压冲压机、传送带、自动合成器、钻井平台 | [电力](/ztech/energy-generators) |
| 应力 | 以传动轴、齿轮连接动力源与机器 | 石磨、机械锯、机械压榨机、部署器、鼓风机 | [应力与传动](/ztech/stress-mechanics) |
| 流体 | 抽水泵与液体管 | 洗矿机、蒸汽轮机、注液器、冷却塔 | [流体](/ztech/fluid-networks) |

电力与应力可通过两种设备相互转换：**应力发电机** 将转动转换为电力，**动力曲柄箱** 将电力转换为转动。

### 单位

- **RF/t**：电力单位。机器说明中的"耗电 4 RF/t"表示该机器工作期间的持续耗电量，发电机的"3 RF/t"表示持续发电量。
- **RPM**：转速。转速越高，应力机器的加工速度越快。
- **SU**：应力。动力源提供应力容量，机器消耗应力；同一网络的总消耗超过总供给时，整个网络停转并冒烟，即"超载"。

## 科技线

Z-Tech 物品需按成就逐级解锁，未达成前置成就时无法合成对应物品。完整的成就树与当前进度可在指南书中查看。主要顺序如下：

1. 指南书 → 铜齿轮 / 传动轴 → 铁板 → 铜线 → 基础电路板 → 基础电池 → 电机 → 机器外壳
2. 机器外壳之后：传送带、发电机、加工耗材，随后为粉碎机、液压冲压机、拉丝机
3. 玫瑰石英 → 磨制玫瑰石英 → 电子管 → 黄铜机壳、转速表与应力表、大型水车与风车
4. 精密构件 → 自动合成器、机械臂、部署器；坚固板 → 强化机壳 → 轻型钻井平台、载具
5. 量子地脉构件 → 量子地脉机壳 → 重型地脉勘探开采平台

此外，**锻造炉** 于机器累计加工 250 件后解锁，**合金炉** 于累计加工 1000 件后解锁。

起步阶段的具体流程见 [开荒指南](/ztech/getting-started)。

## 常见问题

**机器放置后不运转**
请按所属系统检查：电力机器需接入有电的电网；应力机器需连接正在运转的动力源；用水的机器需有水送入。右键打开机器界面，通常会显示缺电、缺料或输出已满等状态。

**传送带上的物品不移动**
传送带两端均需设置支架，支架之间需铺满传送带半砖，且至少一端的支架已接入电网。

**原版漏斗无法向机器送料**
粉碎机、发电机等机器不接受原版漏斗的输入与输出。自动送料请使用溜槽、传送带或机械臂，详见 [仓储与自动化](/ztech/logistics-and-automation)。

**加工产物不会进入相邻的箱子**
加工机的产物保留在机器自身的输出槽中，需手动取出；如需产物自动流转，可采用顶置加工，详见 [加工机器](/ztech/processing-machines#顶置加工)。
