# 快速入门与总览

《Z-Tech 科技》(Zobyic-Tech) 结合了机械动力学与工业电网，支持原位物理加工与可视化机械传动。

---

## 发展阶段概览

工业基地的发展大致可划分为以下阶段：

### 1. 基础开荒期
- **初期动力**：依靠手摇曲柄提供间歇机械动力；
- **基础研磨**：使用石磨磨坊将原矿研磨为矿石粉末，获得翻倍产出；
- **基础材料**：制作机械机壳、传动轴与基础齿轮。

### 2. 机械化
- **自然动力**：利用水车、大型水车或高空风车获取持续的旋转动力；
- **流水作业**：铺设传送带连接各加工节点，使用置物台配合动力冲压机将金属锭冲压为板材；
- **动力调控**：利用齿轮组合进行提速或减速，使用齿轮箱进行垂直或直角换向，配合转速表与应力表监控网络负荷。

### 3. 电气化
- **蒸汽动力**：搭建高压蒸汽锅炉与蒸汽引擎，通过管道持续供水，输出大功率机械动力；
- **动电互通**：使用应力发电机将机械动能转化为电力，或使用燃煤发电机、太阳能板与风力发电机供电；
- **多方块冶炼**：搭建多方块锻造炉与合金炉，贴附加热模块提升冶炼速度。

### 4. 自动化与深层采矿
- **流水线装配**：使用部署器进行序列装配，使用注液器在线灌装；
- **自动化仓储**：搭建多方块物品保险库，配合垂直传送带、分流器、分拣机与机械臂实现自动化分选；
- **载具与采矿**：组装工程车、机动船与飞艇进行物料转运；使用轻型钻井平台或重型地脉开采平台开采矿石。
