# 开荒起步与基础材料

本章介绍 Z-Tech 科技体系的基础机壳、传动构件、金属板材、起步设备与特种工业材料。

---

## 机械机壳

机械机壳是组装大部分机器与自动化设备的外框材料：

### 1. 基础机械机壳
- **配方**：使用平滑石、木板与铁板合成；
- **用途**：用于制造水车、置物台、传送带支架、冲压机等基础设备。

### 2. 黄铜机壳
- **配方**：使用黄铜板与机械机壳合成；
- **用途**：用于制造机械臂、部署器、蒸汽引擎与蒸汽管道等设备。

### 3. 加固机壳
- **配方**：使用钢板或黑钢板搭配耐火砖合成；
- **用途**：用于制造高炉、轻型钻井平台等高负荷机具。

### 4. 量子地脉机壳
- **配方**：以加固机壳为基础，搭配坚固板与哭泣黑曜石合成；
- **用途**：用于组装重型地脉勘探开采平台。

## 传动与基础零件

常用传动构件如下：

| 构件名称 | 材料组成 | 用途说明 |
| :--- | :--- | :--- |
| **传动轴** | 铁锭或钢板 | 直线传递旋转动力，连接动力源与工作机 |
| **黄铜齿轮** | 铜锭与铁板 | 基础传动齿轮，用于传递动力与转向 |
| **青铜齿轮** | 青铜板 | 用于制造齿轮箱、载具发动机与推进螺旋桨 |
| **钢制齿轮** | 钢板 | 耐磨齿轮，用于重型机具与机床 |
| **黑钢齿轮** | 黑钢板 | 用于制造高阶机械与航空发动机 |
| **大齿轮** | 黄铜齿轮与木板/钢板 | 直径较大的齿轮，与小齿轮配合进行 2 倍变速 |
| **小齿轮** | 齿轮与转轴 | 与大齿轮配合进行升速或降速 |
| **反向齿轮** | 双联齿轮组 | 改变旋转方向而不改变传动转速 |

## 金属板与导线

- **金属板材（铁板、铜板、钢板、青铜板、黑钢板、坚固板）**：
  - **手工制作**：前期可在工作台上使用锤子敲打金属锭获得基础板材；
  - **冲压机压制**：建造动力冲压机后，将金属锭放在置物台或传送带上即可自动冲压成板；
  - **用途**：不同金属板分别用于制造机壳、刀具、齿轮与载具外壳。
- **金属导线（铜线、电缆）**：
  - **手工制作**：前期可手工将铜板剪切为铜线；
  - **拉丝机加工**：将铜板送入拉丝机可高效加工出细铜线，用于合成电路板与电缆。

## 搭建首台动力设备：手摇石磨

开荒初期无需电力即可通过手摇曲柄驱动石磨实现矿石产出翻倍：

![初级手摇磨粉示意图](/images/ztech/starter-millstone-setup.png)

### 搭建步骤
1. **放置石磨**：在地面放置【石磨磨坊】；
2. **连接传动轴与曲柄**：在石磨侧面安装一根【传动轴】，并在轴端安装【手摇曲柄】；
3. **放入矿石**：右键将生铁矿或生铜矿放入石磨中；
4. **右键摇动**：持续右键点击手摇曲柄转动转轴；
5. **矿粉产出**：石磨会磨碎原矿并产出 2 份对应的矿石粉末，相比直接烧炼矿石可获得翻倍产出。

## 电网布线规则

电缆用于将发电机输出的电力输送至用电设备：

![电网布线示意图](/images/ztech/power-cable-wiring-setup.png)

1. **直接相邻**：发电机、储能方块与用电设备紧邻摆放时可直接互通供电；
2. **地面电缆**：可直接平铺在地面上进行水平输电；
3. **竖直电缆**：外观为铁链形态，在地面电缆上方垂直堆叠，用于跨楼层垂直供电；
4. **储能方块**：在电网中连接储能方块，用于储存富余电能并在断电时提供缓冲；
5. **自动均衡**：连通的同一电网内部会自动分配电力。

## 常用工具与仪器

### 1. 工业扳手
- **旋转方向**：右键点击传送带支架可反转传送带方向；右键点击齿轮箱可调整输出轴转向；
- **调整构件**：右键点击机械臂或分拣机可调整其朝向与分选角度；
- **开关阀门**：右键点击流体阀门可切换通断；
- **拆卸方块**：潜行状态下右键点击机器方块可将其拆下并回收至背包。

### 2. 电网读取器
- **电网信息**：手持电网读取器右键点击电缆或机器，可查看该电网的总发电功率、总耗电负荷与储能剩余电量。

### 3. 转速表与应力表
- **转速表**：显示连接转轴的实时每分钟转速（RPM）；
- **应力表**：显示当前机械网络的应力负荷百分比与剩余容量。

### 4. 便携式电池与充电棒
- **基础电池与高级电池**：随身携带的电芯，用于为电动工具供电或作为合成材料；
- **便携充电棒**：放在快捷栏中会自动为背包内的电动工具缓慢充电。

### 5. 电动工具（电动钻、电动铲、电动链锯）
- **无耐久消耗**：只要电量充足即可正常作业，消耗电力替代耐久；
- **等级分级**：包含 I 级、II 级、III 级，其中 **III 级电动钻具备 3×3 范围群采** 功能；
- 详见 [电网与发电机](/ztech/energy-generators.md#电动工具)。

### 6. 工程手册与辅助方块
- **指南书**：游戏内置的新手指南界面，右键打开可查阅科技树与合成；
- **工程配方书**：右键打开可速查机床配方；
- **调试之书**：用于快速查看已注册的构件；
- **结构铁管**：空心铁管，用于搭建车间管廊与支架装饰。

## 特种工业材料

### 1. 玫瑰石英与磨制玫瑰石英
- **玫瑰石英**：由红石粉与下界石英合成；
- **磨制玫瑰石英**：使用砂纸或砂轮打磨玫瑰石英制得，用于合成真空电子管与传感器。

### 2. 真空电子管
- 由磨制玫瑰石英、铜线与铁粒合成，是制造机械臂、探测器与智能溜槽的控制元件。

### 3. 未完成精密构件与精密构件
- 传送带上的黄铜板经过多次序列装配（依次安装小齿轮、大齿轮与铁粒）后制成的机械构件，用于合成自动合成器等设备。

### 4. 坚固板
- 由黑曜石粉与金属板压制而成，具有较高的硬度与耐磨性，用于制造锅炉与保险库。

### 5. 合金与矿粉名录
- **钢系**：铁矿粉与煤粉混合制成【生钢合金粉】，烧炼后获得【钢锭】，可加工为【钢板】与【钢制齿轮】；
- **青铜系**：铜矿粉与金属粉混合制成【铜钢合金粉】，烧炼后获得【青铜锭】，可加工为【青铜板】与【青铜齿轮】；
- **黑钢系**：钢锭与黑曜石粉在高炉中冶炼获得【黑钢锭】，可加工为【黑钢板】与【黑钢齿轮】；
- **矿粉**：石磨或粉碎机研磨产出的【铁矿粉】、【铜矿粉】与【黑曜石粉】，用于配制合金生料。

### 6. 电路板
- **基础电路板**：由铁板、铜线与红石合成，用于制造基础机器与控制部件；
- **高级电路板**：结合真空电子管、金导线与覆铜板合成，用于制造高阶机器与高级电动工具。

### 7. 量子与特种构件
- **量子地脉机壳与构件**：使用坚固板、哭泣黑曜石、末影珍珠、高级电路板与下界合金合成，用于制造重型地脉勘探开采平台；
- **超频芯片与散热片**：用于特定设备的加成与散热配件；
- **铁晶体与铜晶体**：由结晶器析出的晶体材料，用于高级电路与终期设备合成。
