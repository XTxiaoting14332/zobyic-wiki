# 开荒指南

本页按游戏进程介绍 Z-Tech 的起步流程，从合成指南书到搭建首条可自动运转的产线。

## 1. 科技线起步

合成【新手指南书】（4 个铁锭 + 1 本书）并右键打开一次，即开始科技线。此后按成就树依次合成：

**铜齿轮 / 传动轴 → 铁板 → 铜线 → 基础电路板 → 基础电池 → 电机 → 机器外壳**

每完成一项，下一项随即解锁。完成机器外壳后，传送带、发电机与加工耗材同时解锁。

::: tip 板材与导线
铁板、铜板可在工作台以 4 个锭按 2×2 合成；4 块铜板可合成 3 根铜线。解锁液压冲压机与拉丝机后，1 个锭可冲压为 1 块板，1 块铜板可拉制为 2 根铜线，材料消耗显著降低。
:::

## 2. 首套供电与加工设备

![首套供电与加工设备](/images/ztech/first-power.png)

1. 土制燃煤发电机：放入煤炭或木炭后发电
2. 电缆：铺设方式与红石粉相同，用于连接发电机与机器
3. 粉碎机：装入研磨头后，可将 1 份粗铁或粗铜粉碎为 2 份矿粉
4. 储能方块（可选）：储存多余电力，机器优先从储能方块取电

发电机、储能方块与机器相邻即视为连通，不相邻时以电缆连接。粉碎机需在耗材槽装入【研磨头】方可工作；研磨头随使用磨损，耗尽后需更换。

右键粉碎机打开界面，将粗铁放入输入槽，通电后即开始粉碎。所得铁粉可在原版熔炉中烧炼为铁锭，每份粗矿最终得到 2 个铁锭。

## 3. 手摇石磨

![手摇石磨](/images/ztech/starter-millstone.png)

1. 手摇曲柄：空手右键摇动，每次持续约 5 秒
2. 传动轴
3. 石磨磨坊：处理圆石、砂砾、骨头、黑曜石等材料

手摇曲柄是无需电力的初级机械动力源。摇动会消耗饱食度，饥饿值低于 6 格时无法摇动。石磨磨坊的配方如下：

| 输入 | 产出 |
| :--- | :--- |
| 圆石 | 砂砾 |
| 砂砾 | 沙子 |
| 花岗岩 / 红砂岩 | 红沙 |
| 骨头 | 4 个骨粉 |
| 黑曜石 | 2 个黑曜石粉 |
| 玫瑰石英 | 磨制玫瑰石英 |

::: warning 石磨不处理矿石
石磨磨坊无法处理粗铁、粗铜。矿石增产需使用电力驱动的粉碎机。
:::

黑曜石粉是强化机壳的必需材料，磨制玫瑰石英是电子管的原料，因此石磨在中后期仍有用途。动力源与传动的详细说明见 [应力与传动](/ztech/stress-mechanics)。

## 4. 矿石处理路线

| 路线 | 所需设备 | 每份粗矿产出 |
| :--- | :--- | :--- |
| 直接烧炼 | 熔炉 | 1 个锭 |
| 高炉 | [高炉](/ztech/smelting#高炉) | 1 个锭，25% 概率额外产出 1 个；速度快于熔炉 |
| 粉碎后烧炼 | 粉碎机、熔炉 | 2 个锭 |
| 粉碎、洗矿、离心 | 粉碎机、洗矿机、离心机 | 4 个锭 |

洗矿机将矿粉洗为"洗净矿粉"，有概率附带燧石或黏土球；离心机将 1 份洗净矿粉分离为 2 个锭。洗净矿粉同时是结晶器培养铁晶体、铜晶体的原料。详见 [加工机器](/ztech/processing-machines)。

## 5. 合金

| 目标产物 | 获取方式 |
| :--- | :--- |
| 合金粉 | 搅拌器或搅拌盆：1 铁粉 → 2 合金粉；合金炉：铁粉 + 铜粉 → 3 合金粉 |
| 青铜粉 | 搅拌器或搅拌盆：1 铜粉 → 2 青铜粉；合金炉：铜粉 + 合金粉 → 2 青铜粉 |
| 钢锭 | 合金粉经熔炉或锻造炉烧炼 |
| 青铜锭 | 青铜粉经熔炉或锻造炉烧炼 |
| 黑钢锭 | 工作台合成：钢锭 + 黑曜石粉 |

钢锭、青铜锭、黑钢锭均可冲压为对应板材。液压冲压机冲压钢板可得到【钻头】，即轻型钻井平台的耗材。

## 6. 机壳

多数机器的配方包含机壳，机壳等级大致对应机器所处的阶段：

| 机壳 | 解锁阶段 | 主要用途 |
| :--- | :--- | :--- |
| 机器外壳 | 科技线前段 | 传送带支架、粉碎机等第一批机器 |
| 黄铜机壳 | 电子管之后 | 搅拌器、动力锯、离心机、蒸汽锅炉、蒸汽引擎、应力机器、洗矿机、机械臂、分流器等 |
| 强化机壳 | 坚固板之后 | 轻型钻井平台、结晶器、蒸汽轮机、动力曲柄箱、动力活塞、高炉等 |
| 量子地脉机壳 | 量子地脉构件之后 | 重型地脉勘探开采平台 |

## 7. 常用工具

- **工业扳手**：右键传送带支架可反转整条传送带；右键装载机、卸载机、鼓风机、分拣机、应力机器等可旋转其朝向；右键驾驶座可登记载具。
- **电网读取器**：手持右键任意电力方块，显示所在电网的节点数、发电机数量、储能余量与用电设备数量。
- **转速应力表**：手持右键任意应力方块，显示所在网络的转速、应力供需及是否超载。
- **超频芯片与散热片**：安装于加工机，用于提速与降温，见 [加工机器](/ztech/processing-machines#超频与散热)。
