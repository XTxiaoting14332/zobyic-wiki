# 流体

流体系统的唯一动力来源是 **泵**。泵从相邻的水源或岩浆源抽取液体，经相连的液体管输送至出口。没有泵时，管道与储罐中的液体均不会流动。

## 抽水泵与液体储罐

![抽水泵与储罐](/images/ztech/pump-tank.png)

1. 水源（不会被消耗）
2. 抽水泵：与水源相邻放置
3. 液体管：六个方向均可连接，相连即构成管网
4. 液体储罐：相邻自动成组，每格容量 8000 mB
5. 抽水泵需接入电网，耗电 2 RF/t

- **抽水泵**（外观为石砖）与水源方块相邻放置，水源不会被消耗。抽水泵需接入电网，耗电 2 RF/t。右键抽水泵可查看管网状态。
- **液体管**（外观为玻璃）六个方向均可连接，相连的液体管构成一张管网，仅可输送水。
- 同一管网存在多个出口时，泵轮流向各出口供液。

## 出口

泵将液体送往管网中各段管道相邻的以下目标：

| 管道相邻方块 | 效果 |
| :--- | :--- |
| 液体储罐 | 注入储罐 |
| 简易蒸汽机、蒸汽锅炉 | 自动补水，无需手动放入水桶 |
| 蒸汽轮机、洗矿机、冷却塔、灌装机、注液器 | 送入机器内部 |
| 炼药锅 | 逐级注满 |
| 空气 | 仅管道末端（只与一段管道相连的一端）将液体排入世界 |

途经管段与空气相邻时不会漏液，仅末端开口排出液体。

## 液体储罐

液体储罐（外观为蓝色染色玻璃）相邻放置时自动成组，容量为方块数 × 8000 mB，有水时罐内显示液位。

- 以泵和液体管向储罐注水，管道与任意一格储罐相邻即可。
- **洗矿机** 与 **蒸汽轮机** 与有水的储罐相邻时，会自动从储罐取水。
- 储罐本身不会向管道输出液体。其他机器用水仍需通过泵与液体管直接供给。

## 岩浆泵

![岩浆泵](/images/ztech/lava-pump.png)

1. 岩浆源：每次抽取消耗一格，会逐渐被抽干
2. 岩浆泵
3. 加强液体管：整个管网须全部使用加强液体管
4. 炼药锅等出口
5. 岩浆泵需接入电网，耗电 4 RF/t

- **岩浆泵**（外观为下界砖）与岩浆源相邻放置，抽取时消耗岩浆源，岩浆湖会逐渐缩小。周围没有岩浆时改为抽水。耗电 4 RF/t。
- 输送岩浆的管网须全部使用 **加强液体管**（外观为遮光玻璃），混入任意一段普通液体管时岩浆不会流动。加强液体管输水时与普通液体管相同。
- 管道末端与空气相邻时，岩浆直接排出，可用于构筑岩浆护城河或焚化装置。
- 注液器同样接受岩浆，可将空桶灌装为岩浆桶。

## 流体阀门与分液池

![阀门与分液池](/images/ztech/valve-splitter.png)

1. 流体阀门：串接于管道中，空手右键切换开关
2. 分液池：一路输入、多路输出，轮流分配

- **流体阀门**（外观为铁门）串接于管道中，空手右键切换开关。关闭时，阀门后方的管道与泵断开。
- **分液池**（外观为炼药锅）可向四周连接多根管道。泵本身即在全部出口之间轮流供液，分液池用于简化分支管道的布置。
