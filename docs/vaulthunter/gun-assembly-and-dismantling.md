# 枪械拆解与组装

在佐比克废土中，猎人除了直接使用战利品原装枪械外，还可通过避难所的军械工坊对枪械进行深度定制。通过将不需要的枪械分解为核心枪身与独立散件，猎人能够打破原有装备的搭配限制，自由选配枪管、握把、枪托、弹匣与战术瞄具，打造极具个人特色的专属改装枪。

---

## 1. 军械工坊设施与位置

军械工坊位于 **0 号避难所主岛西侧**，穿过西侧主干道尽头的浮空木桥即可抵达工坊岛（与东侧靶场对称分布）。

![](/uploads/img-1792664709630-ns4gp.png)<div style="text-align: center">军械工坊</div>

工坊棚内设有三个专用工作台，右键即可开启对应的操作界面：

- **拆解台（砂轮）**：放入背包中的原装枪械进行拆解，提取枪身或部件；
- **拼装台（锻造台）**：自由放置枪身并装配各个部位的散件，实时对比属性并组装为改装枪；
- **部件仓库（木桶）**：存放拆解获得的所有枪身与散件，并提供散件升级、打磨、熔炼与回收服务。

## 2. 枪械部位结构与散件特性

### 六大枪械部位

一把标准枪械由以下部位构成：

1. **枪身（核心枢纽）**：
   - 决定枪械的基本枪种类别、所属厂商、装备品质、元素属性、基础伤害成长以及专属红字或传奇特效；
   - 枪身是整把枪的核心骨架，只能通过野外掉落并拆解获取，不可合成或直接提升品质。
2. **枪管**：
   - 主导枪械的单发伤害倍率、有效射程与弹道基准精准度。
3. **握把**：
   - 影响枪械的连射射速、操控手感与换弹速度。
4. **枪托**：
   - 抑制持续开火时的弹道扩散与后坐力上扬，强化开镜射击稳定性（注：手枪天生没有枪托部位，仅由 5 个部位构成）。
5. **弹匣**：
   - 决定供弹容量与换弹时长。部分高阶弹匣附带独立的「弹匣改装」（如破盾、吸血、撕裂等衍生效果），改装属性随弹匣一同装卸。
6. **瞄具**：
   - 提供开镜视野与变焦倍率，自带对应的视野缩放与命中增益。

### 部件通用性与厂商特装

- **跨枪种装配**：除手枪无法安装枪托外，所有散件均不限制枪种来源。猎人可以自由进行跨界搭配（例如为突击步枪或手枪装配高倍狙击镜）。
- **原厂加成与特装**：散件支持混合搭配不同厂商。当枪身搭配 3 个或以上同厂制造的散件时，可激活强大的厂商 4 件套专属特装共鸣加成。

### 部件品相分阶

每个散件均拥有 0% ~ 100% 的随机品相，品相高低代表该部件在其词条数值浮动区间内的实际表现：

| 品相区间             | 品相称号       | 品相表现说明                       |
| :------------------- | :------------- | :--------------------------------- |
| **0% ~ 59%**   | 标准部件       | 基础属性浮动，满足常规作战需求。   |
| **60% ~ 84%**  | **精制** | 部件属性优秀，数值处于中上游区间。 |
| **85% ~ 97%**  | **完美** | 极高属性加成，接近理论极值。       |
| **98% ~ 100%** | **无瑕** | 词条数值达到当前档位满属性封顶。   |

## 3. 枪械拆解规则

在拆解台放入背包内的枪械，可将其分解为制造散件存入部件仓库：

### 拆解条件与保护机制

- **仅限原装枪械**：野外怪物掉落或宝箱开出的原装枪械均可拆解；已经通过工坊拼装生成的**改装枪无法再次拆解**。
- **安全锁保护**：标记为“收藏”状态的枪械无法拆解。
- **仓库容量保障**：拆解前仓库必须保留至少 2 格空位，若仓库已满需先清理或扩容。

### 拆解产物结算

- **随机保留机制**：每次拆解在扣除手续费后，系统将从该枪的所有部位（枪身、枪管、握把、枪托、弹匣、瞄具）中**等概率随机保留 2 个部件**，其余部位当场损毁折断，无法回收（工坊等级达到满级后有几率多保留 1 个）；
- **弹匣改装绑定**：若随机保留了弹匣，该弹匣原先附带的弹匣改装将完整保留；
- **红字特效风险**：红字专属技能与传奇特效直接与枪身绑定。若枪身在拆解中不幸损毁，其携带的特殊效果将彻底消失，拆解前界面会弹出显眼的风险确认提示。

### 拆解费用

拆解手续费根据枪械的品质阶级、物品等级结算联邦信用币；红字独特武器因结构精密，拆解时需额外消耗一定数量的能量秘晶。

## 4. 枪械拼装法则

在拼装台界面中，猎人可将部件仓库中的枪身与散件拖入装配槽中组装新枪：

![](/uploads/img-1792664907439-ffrhb.png)<div style="text-align: center">拼装台界面</div>

### 自由装配与空槽惩罚

拼装时**仅有枪身是必装核心**，其余部件均允许留空！若某个部位暂无满意散件，可选择暂时空置组装，但枪械将承受对应的机械惩罚：

| 空置部位           | 属性削弱与惩罚表现                                                                                  |
| :----------------- | :-------------------------------------------------------------------------------------------------- |
| **枪管空置** | 武器伤害降低 35%，有效射程削减 60%，弹道基础散布翻倍。                                              |
| **弹匣空置** | 进入**单发直装模式**：无法常规换弹，每次扣动扳机直接从随身备弹池填装 1 发，射击间隔显著延长。 |
| **枪托空置** | 弹道后坐力与连射扩散大幅加剧，开镜射击散布收缩效果减半。                                            |
| **握把空置** | 射速降低 25%，换弹耗时增加 50%。                                                                    |
| **瞄具空置** | 默认采用基础机械瞄具（变焦倍率 1.1x）。                                                             |

### 品质装配门槛

- 稀有（蓝装）与史诗（紫装）部件只能装配在同品质或更高品质的枪身上；
- 传奇（橙装）部件只能装配在传奇或红字枪身上，且每把枪**最多搭载 1 个传奇部件**；
- 带有元素增益词条的散件，必须装配在对应带有元素属性的枪身上方可生效。

### 装备等级与需求门槛

- **基础威力**：拼装枪械的基础伤害与属性成长完全取决于**枪身等级**；
- **佩戴门槛**：拼装成品的**需求使用等级**，由装配的全部主要部件（枪身、枪管、弹匣、枪托、握把）中**最高的一件**决定。若为低级枪身装配了高级枪管，整把枪的使用门槛将提升至高级，但能提前享受高阶部件带来的射程与精准加成。

## 5. 改装负载限制

为防止无节制堆叠顶级部件，每把拼装改装枪均受到严格的**负载上限**约束：

### 枪身品质与负载上限

枪身品质越高，所能承受的高能改装部件越多：

| 枪身品质               | 基础改装负载上限 |
| :--------------------- | :--------------- |
| **普通 (白装)**  | 6 点             |
| **优秀 (绿装)**  | 8 点             |
| **稀有 (蓝装)**  | 10 点            |
| **史诗 (紫装)**  | 12 点            |
| **传奇 (橙装)**  | 14 点            |
| **独特红字枪身** | 13 点            |

*(注：提升工坊等级最多可额外提升 +2 点全局负载上限。)*

### 部件负载消耗

- **制式部件 / 空槽**：0 点负载；
- **白色普通部件**：1 点负载；
- **绿色部件 / 厂商特制部件**：2 点负载；
- **蓝色稀有部件**：3 点负载；
- **紫色史诗部件**：4 点负载；
- **传奇部件**：5 点负载；
- **高精品相额外负载**：散件品相达到 **85% 及以上**（完美或无瑕级别）时，性能超频额外消耗 1 点负载；
- **改装弹匣负载**：附带弹匣改装的弹匣，其总负载按弹匣与改装两者的负载合并计算。

拼装界面右侧会实时显示当前总负载与上限，负载超标时无法完成拼装。

## 6. 改装枪标识、免费命名与专属光柱

- **改装枪专属铭文**：拼装完成的枪械将盖上「改装枪」印记，记录改装者姓名、各个部件明细与品相百分比，并处于不可二次拆解的永久锁定状态。
- **首次免费命名**：拼装成功后，系统提供一次**免费自定义武器名称**的机会（不超过 10 个字），猎人可输入心仪的名字，也可保留系统默认生成的型号代号。
- **动态后缀标识**：根据装配完整度自动赋予后缀：
  - 各部位完整装配且均为非制式部件：**特装**；
  - 存在任意空置部位：**残**；
  - 常规改装搭配：**改**。
- **亮粉色专属光柱**：改装枪在掉落或丢出到地面时，呈现出辨识度极高的**亮粉色光柱**，光柱顶端环绕枪身品质色粒子。若武器装配了传奇部件或采用红字枪身，柱体周围还会伴随金色火花与暗红色流光飞溅。

## 7. 散件养成体系

在部件仓库中，点击未装配的枪身或散件可进入精工养成界面：

### 枪身等级提升

- 猎人可消耗联邦信用币与能量秘晶，将落后等级的低阶枪身直接提升至自身当前角色等级；
- 枪身升级后，其基础伤害数值将按当前等级的伤害曲线重新计算，避免心仪的武器因等级落后而被淘汰。

### 部件打磨

- 消耗信用币与能量秘晶对散件进行微调打磨，**重新随机生成部件品相**（弹匣若带改装会同步重掷）；
- 工坊等级达到 12 级后可解锁「锁定打磨」：打磨后的品相必定不低于当前品相，确保属性稳步提升不倒退。

### 部件熔炼

- 消耗 **3 件同名同枪种** 的多余部件进行高热熔炼；
- 熔炼后保留其中品相最高的一件（原有等级、倍率及改装完整保留），并使其品相在最高值基础上**额外永久提升 +5%**（最高提升至 100% 满品相）。

## 8. 工坊等级与特权解锁

猎人在工坊进行拆解、拼装、打磨与熔炼操作时均可获得工坊经验。工坊等级共有 20 级，随着等级提升将解锁丰厚的工坊特权：

| 工坊等级                      | 解锁特权与被动加成                                                                            |
| :---------------------------- | :-------------------------------------------------------------------------------------------- |
| **Lv.2 起（每双数级）** | 部件仓库上限每次自动扩增 +5 格。                                                              |
| **Lv.3**                | 解锁散件「打磨」功能，可重新随机洗练品相。                                                    |
| **Lv.5**                | 枪械拆解手续费享受 9 折优惠（-10%）。                                                         |
| **Lv.6**                | 解锁散件「熔炼」功能，支持同名部件 3 合 1 提升品相。                                          |
| **Lv.10**               | 改装负载上限永久 +1 点。                                                                      |
| **Lv.12**               | 解锁「锁定打磨」，打磨结果不低于当前品相。                                                    |
| **Lv.15**               | 枪械拆解手续费累计享受 8 折优惠（-20%）。                                                     |
| **Lv.20 (满级)**        | 改装负载上限累计再 +1 点（合计 +2 点）；拆解枪械时拥有**15% 几率额外多保留 1 个部件**。 |

## 9. 部件图鉴系统

工坊主界面右侧收录了全服部件图鉴。只要猎人在拆解、拼装或养成中接触过某种部件，系统便会自动记录该部件曾达到的最高品相：

- **六大图鉴分类**：涵盖枪管、握把、枪托、弹匣与改装、瞄具、传奇部件六大类别；
- **大类集齐奖励**：每集齐一整个大类的所有非制式部件图鉴，不仅可直接领取 10 颗能量秘晶，还可激活一项**永久生效的角色基础属性加成**（叠加在角色坏蛋等级加成中）：
  - **枪管类集齐**：永久全局伤害 +1%；
  - **握把类集齐**：永久暴击伤害 +1%；
  - **枪托类集齐**：永久护盾容量 +1%；
  - **弹匣类集齐**：永久元素持续伤害 +1%；
  - **瞄具类集齐**：永久掉落幸运 +1%；
- **传奇殿堂荣耀**：集齐全部传奇部件图鉴，可获得 30 颗能量秘晶奖励并加冕专属称号 `「军械大师」`。
