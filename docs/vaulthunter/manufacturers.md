# 各家厂商装备特点

在佐比克废土中，武器与防具并非白板数值装备，而是由五大武器军火商与五大专业护盾防务公司设计制造。每一家企业均有极具辨识度的工业美学、核心作战哲学与专属被动机制。

---

## 五大武器军工寡头

佐比克废土中掉落的所有近战剑斧、弓弩与枪械，均属于以下五家军工寡头之一：

| 厂商名称 | 核心作战哲学 | 专属被动机制与枪械特色 | 元素亲和偏好 |
| :--- | :--- | :--- | :--- |
| **先锋重工** | 精准连击·护盾反哺 | **连击增伤**：连续打击同一目标伤害递增；<br>**护盾反哺**：每次命中稳定为自身回充 3 点护盾；<br>**枪械特性**：三连点射模式，精度极高，后坐扩散极慢。 | 电击、燃烧 |
| **天穹化学** | 极化元素·持续异常 | **全系元素**：全系枪刀天生绑定元素属性，元素触发几率 +50%；<br>**极化熔渣**：独家垄断熔渣武器，命中使目标陷入 200% 易伤状态。 | 全谱系专精 (燃烧、酸蚀、电击、熔渣) |
| **荒原游侠** | 纯粹动能·致死暴击 | **暴击乘算**：近战跳劈与远程爆头暴伤额外乘算 **+75%**；<br>**破片跳弹**：子弹或箭簇命中实体后破碎反弹向临近敌人；<br>**枪械特性**：均为半自动击发（点多快打多快），爆头 2.5 倍暴伤并跳弹。 | 纯动能为主，蓝装及以上才衍生酸蚀与电击 |
| **泰坦动力** | 重装压制·范围爆轰 | **动能爆破**：挥砍或重弹命中在着力点引发 **2.5 格范围**冲击波；<br>**枪械特性**：发射爆炸子弹，命中引发范围撕裂破甲爆炸，射速较慢。 | 燃烧、酸蚀 |
| **掠食生物** | 极致攻速·生命虹吸 | **极速挥砍**：生物神经连接带来极高挥刀攻速；<br>**生命吸取**：每次命中敌人吸取 2 点真实生命值；<br>**枪械特性**：超大弹匣容量但散布较大，击杀敌人自动回填 3 发子弹。 | 酸蚀、燃烧 |

## 五大护盾防务工造

由于佐比克废土移除了原版自然回血，胸甲槽位的能量护盾成为唯一的生存保障。五大防务企业开创了五种截然不同的生存流派：

| 防务品牌 | 核心防御流派 | 专属技术特质与战术定位 |
| :--- | :--- | :--- |
| **磐石防务** | **龟壳重装** | 视肉身如草芥，穿戴时强制削减穿戴者部分生命上限（-2 ~ -10 HP），换取厚如装甲战车般的**极限超绝护盾容量**与基础免伤。适合远程狙击手与防秒杀流派。 |
| **泛生医疗** | **拟态自适应** | 尊崇生命至上，穿戴直接大幅**提升穿戴者生命上限**（+4 ~ +12 HP），并在受击后短时间内生成临时自适应抗性。适合近身冲锋与容易被穿透伤害打中肉身的攻坚者。 |
| **极光工造** | **超能增幅** | 以攻代守。在**护盾处于 100% 满充盈状态**下，武器发射将消耗少量护盾，转化为**毁天灭地的增幅致命一击**。适合潜行暗杀与单发高伤狙击。 |
| **震荡动力** | **新星爆震** | 以暴制暴。内置反物质微型反应堆，在**护盾被彻底轰碎的刹那**，向周围 360 度引发大范围爆炸冲击波。适合被大量近战小怪围攻时的贴脸解围。 |
| **铁穹实业** | **超导极速充能** | 采用蜂鸟磁阻技术，拥有全废土**最短的充能延迟（通常仅 2.0 秒）与飞速回充速率**，脱战数秒即可迅速满盾复原。适合高机动走位与掩体战。 |
