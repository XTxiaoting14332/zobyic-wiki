# New-U与快速旅行

在佐比克废土中，**战地检查点 (New-U Checkpoint)** 与 **快速旅行 (Fast Travel)** 彻底解耦为两个独立运行的高效系统，共同构成了猎人的复活与移动网络。

---

## 一、 战地 New-U 3×1 重构立柱 (自动感应存档)

### 1. 立柱构造与方块构成

战地立柱占地仅 1×1 方块，总高 3 格：

![](/uploads/img-1791959782139-yyi29.png)<div style="text-align: center">位于 Fast Travel 附近的一个 New-U 重构站</div>

### 2. 走近 3.5 格自动感应同步

废土全境铺设了 **24+ 座战地立柱**：

- **重生点保存**：玩家经过或走近立柱 **3.5 格** 以内自动将玩家的死亡复活点更新绑定至此。
- **50 米雷达近距提示**：当接近任何未绑定的立柱 50 米时，ECHO 探测器自动发出提示音，并在屏幕 Actionbar 与聊天框提示距离与八向方位。

### 3. 随身罗盘一键锁定 (`/vh cp` 或 鼠标左键点击罗盘)

- 玩家只需**手持罗盘点击左键**（或在控制台输入指令 `/vh cp`），随身罗盘指针将立即**自动计算并精准锁定距离当前最近的 New-U 战地立柱**。
- 聊天框与 Actionbar 弹出详细的直线距离与前进方位（如 `[ECHO 罗盘] 目标: 荒原近郊重构柱 (直线距离: 82m, 方位: 东北)`），沿着指针前行即可快速抵达并存档。

### 4. 死亡量子重构与费用扣除

- 阵亡时**保留所有随身装备、道具与背包物资**；
- 优先在**最近一次自动感应绑定的 New-U 立柱**处重构复活；
- 扣除当前持有现金的 **7% 作为数字化服务费**；

## 二、 先锋重工快速旅行网络 (Fast Travel)

快速旅行网络连接了 0 号避难所浮空城与佐比克废土各大核心战略前哨站。猎人只需在哨站的磁石终端完成一次交互即可永久点亮该节点，随后可在任意已激活哨站之间实现无消耗即时传送。

![](/uploads/img-1791959945686-t2zg6.png)<div style="text-align: center">Fast Travel 传送站</div>

### 1. 冲天青色信标塔 (Sky Beacon Beam)

- 部署在全图各大战略要地的核心前哨站（如避难所、干旱东/西哨卡、强盗峡谷、极地科考站、熔岩要塞等）。
- 采用 3×3 科技终端地台与**高能青色信标光柱**，数百米开外抬头即可直观辨识宏观哨站方位。

### 2. 核心前哨站坐标名录

| **佐比克荒原·着陆区** | Lv.1     | `(0, 0)`        |
| **干旱荒原·东哨卡**   | Lv.3     | `(200, 50)`     |

### 3. ECHO 战术雷达大地图 (`/vh map` 或 鼠标右键点击罗盘)

- 手持罗盘**点击右键**（或输入 `/vh map`）可唤起 7 大前哨站雷达大地图面板。
- 面板列出所有前哨站的名称、推荐等级、坐标、直线距离与航向方位。
- 点击特定哨站条目，可将罗盘指针切换锁定至该远距离宏观前哨站。

### 4. 磁石终端远距离传送

- 走到前哨站的磁石终端前右键交互即可点亮该枢纽；再次右键打开快速旅行网络界面，即可在所有已激活的前哨站之间自由瞬间传送。
