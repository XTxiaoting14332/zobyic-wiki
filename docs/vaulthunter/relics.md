# 圣物装备名录

圣物（Relic）是承载着古代伊利迪亚异星科技与废土工业芯片的核心被动构件。圣物无需主动操作，只需装载在专用防务插槽中，即可为猎人的军械、元素、生存与掉落收益带来全面的百分比词条加成。

## 品质分阶与数值成长公式

### 1. 品质与词条条数

圣物的稀有度决定了其能承载的被动词条数量上限（同一件圣物内不会出现重复词条）：

| 装备品质            | 稀有度颜色 | 词条数量 | 命名规则示例   | 品质数值倍率 |
| :------------------ | :--------- | :------- | :------------- | :----------- |
| **普通 (白)** | 白色       | 1 条     | 白·杀戮圣物   | 1.0 倍       |
| **非凡 (绿)** | 绿色       | 2 条     | 改良·枪手圣物 | 1.25 倍      |
| **稀有 (蓝)** | 蓝色       | 2 条     | 精良·致命圣物 | 1.5 倍       |
| **史诗 (紫)** | 紫色       | 3 条     | 史诗·壁垒圣物 | 1.8 倍       |
| **传奇 (橙)** | 橙色       | 3 条     | 传奇·先锋圣物 | 2.2 倍       |

### 2. 词条数值成长算法

圣物词条的实际数值受到**词条基准区间**、**品质倍率**以及**物品等级倍率**三重乘算：

- **词条最终数值** = 随机基准区间 × 品质倍率 × 等级倍率
- **等级倍率公式** = 1.0 + 0.5 × (当前物品等级 - 1) / (最大等级 50 - 1)
  - Lv.1 圣物等级倍率为 **1.0 倍**；
  - Lv.50 满级圣物等级倍率达到 **1.5 倍**。
- **针对性词条权重衰减**：在随机抽取词条时，指定特定枪种增伤、枪种弹匣容量、特定厂商或手雷携带上限的 16 种针对性词条权重减半（权重 0.5，通用词条权重 1.0），确保高泛用性词条拥有稳定的出现几率。
