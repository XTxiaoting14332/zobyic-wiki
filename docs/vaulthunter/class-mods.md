# 职业模组装备名录

职业模组（Class Mod，简称 COM）是猎人构筑核心流派、跨越技能点上限并激活高阶被动质变的核心装备。通过将职业芯片植入战术头盔槽位，猎人可直接为对应技能树赋予额外点数，甚至突破原有技能上限，使各职业在团队与单兵作战中展现极致特化。

---

## 装备佩戴规则与生效机制

### 1. 穿戴栏位与外观隐匿
- **装备槽位**：职业模组佩戴在**头盔栏位**（Helmet slot，`EquipmentSlot.HEAD`，外观为唱片残片）。
- **纯战术饰品**：职业模组属于纯属性与技能构件，移除了原版头盔的护甲防御点数（`Armor = 0`）。装备后在角色头部不会显示任何原版方块或头盔模型，不占用宝贵的快捷栏与背包主格。
- **佩戴方式**：在背包中手持职业模组点击右键，或使用 `Shift + 左键` 即可直接穿配进头盔栏。
- **世界隔离**：职业模组的技能加成与被动属性仅在 `vh_world`（佐比克废土）与 `vh_sanctuary`（0 号避难所）生效，返回原版生存世界时被自动隔离。

### 2. 职业契约绑定与不符警告
- **专属绑定**：每一件职业模组在生成时均严格锁定某一特定职业（突击兵、塞壬、狂枪手、刺客）。
- **匹配生效判定**：
  - 只有当猎人当前的实际就职职业与模组契约一致时，模组包含的技能加成与属性才会全部生效；
  - 若佩戴了其他职业的模组，或角色尚未达到 Lv.5 选择职业，模组将被挂起（状态栏与随身菜单显示未生效告警），不会提供任何加成；
  - 更换职业或换装不同模组时，服务端会在 10 ticks（0.5 秒）内自动重算全套被动属性与技能池。

### 3. 等级门槛与强制脱卸保护
- 每件职业模组均带有固定的**物品等级**与**需求等级**（`req_level`）。
- 服务端以 10 ticks（0.5 秒）周期持续轮询校验。若猎人佩戴了超出自身角色等级的高阶职业模组，系统会自动**将其卸下并收纳回玩家背包**（若背包已满则掉落在脚下安全位置），并在屏幕中央弹出等级不足警报，防止越阶穿戴。

## 技能加成规则与突破上限

### 1. 突破技能上限机制
职业模组是佐比克废土中唯一能够**强行突破技能等级上限**的途径：

- **实际生效技能等级** = 玩家自身投入点数 + 职业模组额外加成点数
- **突破上限倍增**：原本上限为 5 点的技能，在史诗或传奇模组强化下可达到 6~10 级，各项百分比增益将按照单级数值线性成倍放大；
- **零投入直接激活**：即使猎人在该技能上尚未投入任何点数（投入为 0 点），只要佩戴了对应技能加成的职业模组，该技能**立即以模组加成等级生效**（例如直接激活为 4 级），无需等待技能树层级爬升即可提前享用该技能效果。

### 2. 层级解锁独立判定
- 职业模组所赋予的额外技能点**不计入**技能树各层级解锁所需的前置点数统计；
- 解锁技能树第 2~6 层所需的 5 点、10 点、15 点、20 点与 25 点门槛，仍必须由猎人升级获得的真实技能点真实投入达成。

### 3. 界面动态实时联动
在佩戴职业模组的状态下输入 `/vh skills` 打开技能树：
- 对应技能图标的角标数量会动态反映实际生效等级；
- 技能名称旁边呈现亮青色加成标识（如 `+4`）；
- 悬停悬浮窗详细注明 `当前等级: 投入点数+模组点数/上限`，并高亮提示模组跨界增益。

## 品质分阶、加点规模与属性算法

职业模组共分为五大品质阶级。品质越高，强化技能的数量与点数越高，并附带更强的被动属性：

| 品质分级 | 稀有度颜色 | 命名规则示例 | 强化技能数量与加点分配 | 附加被动属性条数与规格 |
| :--- | :--- | :--- | :--- | :--- |
| **普通 (白)** | 白色 | 突击兵·工程师模组 | 2 个技能（**+1 / +1**） | 无附加属性 |
| **非凡 (绿)** | 绿色 | 改良·塞壬·医者模组 | 3 个技能（**+2 / +1 / +1**） | 1 条固定基础属性 |
| **稀有 (蓝)** | 蓝色 | 精良·狂枪手·疯狗模组 | 3 个技能（**+3 / +2 / +1**） | 1 条固定基础属性 |
| **史诗 (紫)** | 紫色 | 史诗·刺客·幽影模组 | 3 个技能（**+4 / +3 / +2**） | **2 条属性**（1 条固定 + 1 条随机） |
| **传奇 (橙)** | 橙色 | 传奇·铁幕指挥官模组 | **5 个技能（+5 / +4 / +4 / +3 / +3）** | **2 条强力固定属性**（专属型号） |

### 1. 模组被动属性数值规格
- 职业模组所携带的固定与随机属性数值受等级与品质倍率加权，基础数值基准按同等级同品质圣物的 **75%** 折算（`STAT_SCALE = 0.75`），核心战略价值侧重于技能加点；
- 模组上的属性加成会自动并入猎人的全局圣物属性池统一生效。

### 2. 史诗 (紫) 品质随机附加属性池
史诗品质模组除自身型号绑定的 1 条固定属性外，必定从以下 8 种高泛用性属性池中随机抽取第 2 条属性：
- **生命上限**
- **护盾容量**
- **换弹速度**
- **枪械射速**
- **暴击伤害**
- **主动技能冷却速度**
- **枪械伤害**
- **护盾充能速度**

### 3. 枪种弹匣容量附赠词条 (30% 几率)
非凡（绿）、稀有（蓝）、史诗（紫）与传奇（橙）品质的职业模组在生成时，**拥有 30% 独立几率额外附带一条本职业偏好枪种的弹匣容量加成属性**（数值同样受品质与等级成长，不占用上述固定与随机词条位）：
- **突击兵**：突击步枪弹匣容量（扩容弹匣）
- **塞壬**：冲锋枪弹匣容量（弹鼓）
- **狂枪手**：手枪弹匣容量（加长弹匣）或 霰弹枪弹匣容量（霰弹带）
- **刺客**：狙击步枪弹匣容量（长弹仓）

### 4. 传奇型号特殊机制
- 每个职业拥有 **1 种独一无二的专属传奇型号**（橙装），无法被其他职业替换；
- 传奇型号横跨该职业的 **3 棵技能树**，精选 5 个决定性核心技能，分别赋予 **+5 / +4 / +4 / +3 / +3** 的终极强化；
- 传奇模组自带附魔流光效果，并固定绑定两条最契合该职业流派的核心属性（若触发 30% 几率还会再附赠一条偏好弹匣扩容）。

## 掉落几率与智能偏向规则

- **掉落替代比例**：荒原敌人与物资箱掉落装备时，有 **10% 概率** 替代武器或护盾生成职业模组（`class_mods.drop_share: 0.10`）。
- **智能偏向掉落机制 (Smart Loot)**：
  - 当怪物由猎人击杀掉落时，生成的职业模组有 **60% 权重** 必定定向为击杀者当前所就职的职业；
  - 剩余 **40% 权重** 在全职业模组池中随机抽取；
  - 该机制兼顾了个人开荒构筑的成型速度与联机小队成员之间交换互通的玩法乐趣。
