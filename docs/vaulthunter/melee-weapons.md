# 近战刀剑名录

在佐比克废土中，近战武器（长剑、重剑、短刀、马刀）继承了各大厂商鲜明的近战流派。近战武器具备无限耐久，在跳跃下落时挥砍可触发暴击，并自动触发所属厂商的被动技能（如护盾反哺、范围爆轰、暴伤跳弹或吸血）。
