# 能量护盾装备名录

能量护盾是佐比克废土中猎人生存的第一道生命线。任何直接伤害在穿透肉身前都会被能量护盾的偏折力场全额抵扣。各大防务军工财团针对不同战术场景，研发了六大机制迥异的护盾流派。

---

## 护盾运转机制与穿戴规则

### 1. 穿戴栏位与受击吸收

- **佩戴要求**：能量护盾必须佩戴在**胸甲槽位**。未穿戴有效护盾进入荒原等同于以肉身暴露在敌方火力之下。
- **优先抵扣**：受到近战劈砍、箭矢投射、枪械弹丸或爆炸冲击时，伤害优先全额扣除护盾值。只要护盾值大于 0，肉身生命值受到绝对保护。
- **抗性与弱点**：
  - 护盾存续期间具备天生的**偏折减伤**与**元素持续伤害减免**。
  - **电击伤害**是护盾克星：电击元素攻击命中护盾时强制造成 **2.0 倍致命暴击伤害**，并无视护盾的元素减免机制。

### 2. 核心三维参数

每件护盾在面板上均标明以下三个核心工作参数：

- **护盾容量**：力场能承受的最大总伤害值。容量归零即发生破盾。
- **充能延迟**：承受最后一次伤害后，开始回充之前必须等待的脱战冷却秒数（单位：秒）。冷却期间若受到任何后续伤害，倒计时立即重置刷新。
- **充能速率**：延迟倒计时结束后，每秒自动回复的护盾点数（单位：点/秒）。

## 独特红字护盾

废土中击败特定领地首领时，有几率获取专属红字能量护盾。此类护盾打破常规数值与防护逻辑，拥有独特的专属铭文与特殊防护特技，留待猎人在探索与讨伐中自行发掘。
