# 游戏基本命令

《宝库猎人》插件的所有功能均整合于 `/vh` 根命令下。命令体系分为面向普通玩家的探索交互指令与面向服主管理员的运维调试指令。

---

## 玩家常用指令

所有已进入服务器的玩家均默认拥有以下命令的执行权限：

| 命令语法 | 简写 / 触发方式 | 功能详细说明 |
| :--- | :--- | :--- |
| `/vh join` | 无 | **进入废土**：系统将暂存玩家在原世界的所有背包物资、经验、生命与药水状态，随后将玩家安全传送至佐比克着陆区，并下发初始开荒物资。 |
| `/vh leave` | 无 | **安全退出**：退出废土世界，返回原世界出生点。玩家在原世界的生存背包与等级 100% 完整复原，废土装备安全保存在独立数据库。 |
| `/vh menu` | `/vh gui` 或直接输入 `/vh` | **猎人个人总览菜单**：打开集成了属性面板、前哨站传送、黑市扩容与随身商店的综合控制面板。 |
| `/vh skills` | `/vh skill` 或 `/vh talent` | **职业与技能树界面**：打开四大职业选择界面或三系技能树加点面板，支持洗点重选与滚轮防误触保护设置（主动技能绑定在快捷栏第 9 格，按 `9` 键释放）。 |
| `/vh cp` | 鼠标左键点击罗盘 | **锁定最近重构柱**：系统计算并驱动随身罗盘指针精准锁定距离当前最近的 3×1 New-U 战地立柱，并在聊天框与 Actionbar 反馈直线距离与方位。 |
| `/vh map` | 鼠标右键点击罗盘 | **打开 ECHO 雷达大地图**：呼出覆盖全图的远距离雷达面板，展示坐标、推荐等级、距离与航向方位，并可点击切换罗盘导航航标。 |
| `/vh bounty` | `/vh bounties` | **战术雇佣悬赏板**：呼出合约面板，支持接取/交付首领通缉令、常规清剿、弱点特训，以及查看每日日常与每周周常悬赏。 |
| `/vh badass` | 无 | **坏蛋等级强化**：打开满级长线成长加点面板，消耗坏蛋代币在随机抽取的 3 项属性中选择 1 项进行永久强化。 |
| `/vh mayhem [层级]` | 无 | **混乱模式难度**：查看当前混乱模式倍率与今日突变规则；满级玩家可输入目标层级（0~10）切换挑战难度。 |
| `/vh exchange` | 无 | **货币双向兑换所**：查看当前汇率与限额。支持 `/vh exchange in <主服货币>` 与 `/vh exchange out <信用币>` 互相安全兑换。 |
| `/vh crates` | 无 | **废土物资箱仓储**：查看持有的物资箱数量。在主服世界使用 `/vh crates open <品级> [数量]` 开启产出原版建材与矿石。 |
| `/vh sdu` | 无 | **黑市空间扩容**：呼出 SDU 空间折叠终端界面，消耗精英怪掉落的【能量秘晶】，逐步解锁被锁定的主背包行数与四大枪械备弹池上限。 |
| `/vh shop` | 无 | **黑铁军火贩卖机**：呼出随身军火采购界面，使用联邦信用币购买基础武器、各口径枪械弹药包与军用急救医疗包。 |
| `/vh stuck` | `/vh unstuck` | **战地安全脱困**：卡进地形缝隙或无法移动时使用。保持原地静止 3 秒后，系统自动安全移送至附近的平整地面。 |
| `/vh nv` | `/vh nightvision` | **夜视护目镜开关**：手动开启或关闭战术微光夜视（荒原入夜时系统默认自动开启）。 |
| `/vh boss list` | 无 | **首领雷达状态**：查看荒原 9 大领地首领当前的存活状态、重生剩余倒计时与坐标。 |
| `/vh sound [1~13]` | 无 | **试听 New-U 广播**：试听先锋重工官方 New-U 重构广播语音台词（需加载服务器资源包）。 |

## 管理员运维指令

以下指令需要管理员权限节点 `vaulthunter.admin`（或 OP 身份）：

| 命令语法 | 参数详细说明 | 功能描述 |
| :--- | :--- | :--- |
| `/vh admin` | 无 | 打开管理员总控面板（包含物资箱掉落表可视化配置、首领管理、装备库检索与联动设置）。 |
| `/vh give <物品ID> [玩家]` | `<物品ID>`: 注册物品标识<br>`[玩家]`: 目标玩家名（留空则默认自身） | 直接向指定玩家发放指定的废土定制物品（包括所有刀剑、弓弩、枪械、护盾、圣物、医疗包与专用弹药）。 |
| `/vh relic <品质> [等级] [玩家]` | `<品质>`: common ~ legendary<br>`[等级]`: 目标等级<br>`[玩家]`: 目标玩家名 | 为指定玩家生成一件指定品质与等级的随机词条圣物。 |
| `/vh rare [种类]` | `[种类]`: 稀有精英ID（留空随机） | 在执行者面前直接强制生成一只指定的荒原具名稀有精英怪（不受刷新率与区域方格限制）。 |
| `/vh boss spawn <首领ID>` | `<首领ID>`: 首领标识（如 nine_toes） | 强制在对应领地刷新指定的领地首领。 |
| `/vh boss tp <首领ID>` | `<首领ID>`: 首领标识 | 立即将自身传送至指定首领的领地刷新点。 |
| `/vh addcash <金额> [玩家]` | `<金额>`: 整数金额<br>`[玩家]`: 目标玩家名 | 为指定玩家注入对应数额的联邦信用币储备。 |
| `/vh addcrystals <数量> [玩家]` | `<数量>`: 整数数量<br>`[玩家]`: 目标玩家名 | 为指定玩家增加能量秘晶（用于 SDU 空间扩容）。 |
| `/vh reload` | 无 | 热重载核心配置文件 `config.yml` 与物资箱掉落表 `supply_crate_loot.yml`，无需重启服务器。 |
| `/vh datareload <玩家>` | `<玩家>`: 离线玩家名 | 配合文件备份，热重载恢复指定玩家的坏蛋数据与背包存档文件。 |

## 权限节点配置速查

- **`vaulthunter.use`**：基础玩家权限，允许执行所有常规游玩指令（默认向所有玩家开放）。
- **`vaulthunter.admin`**：最高管理员权限，允许执行所有运维、管理面板与物品生成调试指令。
