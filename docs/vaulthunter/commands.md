# 游戏基本命令

《宝库猎人》插件的所有功能均整合于 `/vh` 根命令下。命令体系分为面向普通玩家的探索交互指令与面向服主管理员的运维调试指令。

---

## 玩家常用指令

所有已进入服务器的玩家均默认拥有以下命令的执行权限：

| 命令语法 | 简写 / 触发方式 | 功能详细说明 |
| :--- | :--- | :--- |
| `/vh join` | 无 | **进入废土**：系统将暂存玩家在原世界的所有背包物资、经验、生命与药水状态，随后将玩家安全传送至佐比克着陆区，并下发初始开荒物资。 |
| `/vh leave` | 无 | **安全退出**：退出废土世界，返回原世界出生点。玩家在原世界的生存背包与等级 100% 完整复原，废土装备安全保存在独立数据库。 |
| `/vh cp` | 鼠标左键点击罗盘 | **锁定最近重构柱**：系统计算并驱动随身罗盘指针精准锁定距离当前最近的 3×1 New-U 战地立柱，并在聊天框与 Actionbar 反馈直线距离与方位。 |
| `/vh map` | 鼠标右键点击罗盘 | **打开 ECHO 雷达大地图**：呼出 7 大核心前哨站的远距离雷达面板，展示坐标、推荐等级、距离与航向方位，并可点击切换罗盘导航航标。 |
| `/vh sdu` | 无 | **黑市空间扩容**：呼出 SDU 空间折叠终端界面，消耗精英怪掉落的【能量秘晶】，逐步解锁被锁定的主背包行数与四大枪械备弹池上限。 |
| `/vh shop` | 无 | **黑铁军火贩卖机**：呼出随身军火采购界面，使用联邦信用币购买基础武器、各口径枪械弹药包与军用急救医疗包。 |
| `/vh menu` | 直接输入 `/vh` | **猎人个人总览菜单**：打开集成了属性面板、前哨站传送、黑市扩容与随身商店的综合 GUI 控制面板。 |

## 管理员运维指令

以下指令需要管理员权限节点 `vaulthunter.admin`（或 OP 身份）：

| 命令语法 | 参数详细说明 | 功能描述 |
| :--- | :--- | :--- |
| `/vh give <物品ID> [玩家]` | `<物品ID>`: 注册表中的物品标识字符串<br>`[玩家]`: 目标玩家名（留空则默认自身） | 直接向指定玩家发放指定的废土定制物品（包括所有厂商刀剑、弓弩、枪械、护盾、圣物、医疗包与专用弹药）。 |
| `/vh addcash <金额> [玩家]` | `<金额>`: 整数金额数值<br>`[玩家]`: 目标玩家名 | 为指定玩家注入对应数额的联邦信用币储备（可在贩卖机消费或扣减死亡复活费）。 |
| `/vh addcrystals <数量> [玩家]` | `<数量>`: 整数秘晶数量<br>`[玩家]`: 目标玩家名 | 为指定玩家增加能量秘晶（专门用于 SDU 背包扩容）。 |
| `/vh reload` | 无 | 热重载插件的核心配置文件 `config.yml`、重构点配置与语言文本，无需重启服务器。 |
| `/vh admin` | 无 | 打开管理员调试面板，包含一键刷怪测试、Boss 状态监控与全物品检索发放界面。 |

---

## 权限节点配置速查

- **`vaulthunter.use`**：基础玩家权限，允许执行 `/vh join`、`/vh leave`、`/vh cp`、`/vh map`、`/vh sdu` 与 `/vh shop`（默认向所有玩家开放）。
- **`vaulthunter.admin`**：最高管理员权限，允许执行 `/vh give`、`/vh addcash`、`/vh addcrystals`、`/vh reload` 以及打开管理员面板。
