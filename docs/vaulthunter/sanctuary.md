# 避难所与安全区

0 号避难所（Sanctuary）是佐比克星地表大灾变后，依靠先锋重工城市级反重力浮空引擎升入近地轨道的唯一非武装中立空港。这里是所有宝库猎人降临、整备行囊、接取悬赏与进行黑市交易的绝对安全区。

## 1. 避难所环境与安全法则

- **空间定位**：悬浮于虚空之上，核心中央广场坐标为 `(0, 0, Y=100)`。
- **绝对安全领域**：
  - 全域禁用玩家间伤害；
  - 严禁任何敌对怪物与野生生物生成；
  - 严禁任何破坏方块或爆炸行为，为猎人提供绝对和平的整备环境。
- **中央着陆与空投平台**：连接废土轨道的传送枢纽。玩家在此可通过快速旅行信标塔直接空投前往佐比克地表的各大前哨站。

---

## 2. 金钥匙宝箱

金色宝箱位于 0 号避难所快速旅行终端东侧 3 格处，上方悬浮有全息指示面板：

![](/uploads/img-1791960257078-t9acz.png)

- **钥匙获取途径**：
  - **每周自动发放**：系统每周自动为每位猎人账户注入 1 把金钥匙（个人最多存储上限为 5 把）；
  - **周常悬赏奖励**：完成 ECHO 每周大型周常合约，同样稳定奖赏金钥匙；
  - **服务器活动特赏**：重大运维节点与全服挑战成就额外空投。
- **开箱产出规则**：
  - 右键金色宝箱弹出开箱确认界面，消耗 1 把金钥匙开启；
  - 每次开启固定喷出 **2 件** 完全适配玩家当前角色等级的高阶装备（包含各厂商刀剑、弓弩、现代枪械与能量护盾，均附带随机词条）；
  - 基础品质为**史诗 (紫装)**，且每件装备拥有 **15% 独立概率** 直接升阶为**传奇 (橙装)**，是平民猎人跨越装备门槛与攻坚高级圈层首领的重要依托。

## 3. 避难所商业街与核心功能区

避难所聚集了废土各大派系的常驻代表与技术代理人：

### 自由商盟 · 黑铁军火行

- **主持代表**：“火药桶”加里
- **服务项目**：设立有多台黑铁自动贩卖机。向猎人平价供应手枪、冲锋枪、步枪、霰弹枪的各型号弹药包，以及各厂基础白装/绿装武器。

### 泛生战地诊所

- **主持代表**：“缝合者”奎恩
- **服务项目**：专营泛生医疗旗下专利的 `军用急救医疗包`。由于废土环境彻底禁用了原版饱食度自然回血，奎恩的纳米医疗包是猎人深入高危圈层的生命底牌。

### “铁肺”鲁多克 SDU 空间走私坊

- **主持代表**：“铁肺”鲁多克
- **据点位置**：避难所底层生锈管道区。
- **服务项目**：鲁多克掌握着战前绝密的亚原子空间压缩技术。他拒收普通信用币，**仅接受猎人从地表带回的远古高维【能量秘晶】(◆)**。玩家在此可突破战术背包空间限制（扩容至 36 格全开），并解锁各大枪种备弹与手雷携带上限。

### 联邦资产汇兑处与个人储物柜

- **服务项目**：设立有大型保险库终端。猎人可在不同世界之间安全存取跨维度物资与稀有矿石，防止带入废土后意外遗失。
