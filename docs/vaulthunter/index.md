# 快速入门与总览

《宝库猎人》(Zobyic-VaultHunter) 是运行在专属隔离世界 `vh_world`（佐比克废土）与 `vh_sanctuary`（0号避难所浮空城）中的 ARPG 刷宝玩法。玩法具备独立的背包隔离、代谢静滞护盾机制、全天候高频交火、五大军工武器厂商、六大护盾防务流派、现代枪械射击以及前哨站传送网络。

---

## 跨世界数据安全隔离规则

进入与离开废土实行严格的背包与状态置换机制，确保玩家在原版生存世界的进度不受干扰：

- **进入废土 (`/vh join`)**：系统自动将玩家在原世界的生存背包、生命值、饱食度、经验等级与药水状态完整暂存至数据库。随后传送至避难所或荒原着陆区，自动配发废土专属物资（木剑、简易皮革护盾与便携箭袋）。
- **离开废土 (`/vh leave`)**：随时输入该指令可脱离废土返回主世界出生点。玩家在原生存世界的全部物品、装备与等级 100% 完整复原。在废土中获得的武器、护盾、代币与秘晶安全保存在猎人独立档案中。

## 新手开荒步骤指南

1. **第一步：检查初始防护**  
   出生时胸甲栏位已自动配备 `简易皮革护盾`（容量 50 点，充能延迟 4.5 秒）。佐比克废土移除了原版自然回血，切勿在荒野脱下护盾。
2. **第二步：清理低阶强盗**  
   离开着陆区 50 米安全缓冲带后，击杀沿途刷新的 1~3 级近战或远程狂徒。拾取掉落的白色/绿色武器，并收集地面掉落的联邦信用币。
3. **第三步：就近绑定复活点**  
   手持随身罗盘点击左键（或输入 `/vh cp`），罗盘指针将自动指向距离最近的 New-U 战地立柱。跑过立柱 3.5 格以内即可自动完成死亡复活点绑定。
4. **第四步：购买医疗储备与扩容背包**  
   累积到一定信用币后，输入 `/vh shop` 购买 1~2 个 `军用急救医疗包` 放置在快捷栏备用；精英怪物掉落【能量秘晶】后，输入 `/vh sdu` 扩容主背包行数。
