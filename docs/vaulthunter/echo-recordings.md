# ECHO 录音机与历史档案

在佐比克废土的探索征途中，散落着历代开拓者、公司雇员、科研人员与各路流亡者留下的**遗落的 ECHO 录音机**。这些音频黑匣子忠实记录了佐比克大灾变前后的历史碎片与地理变迁。


---

## 1. 录音机收集与识别机制

### 双色全息光柱辨识
当怪物掉落或地表散落遗落的 ECHO 录音机时，地面将升起专属的粒子识别光柱，与常规装备、货币及弹药光柱明显区分：
- **光柱色彩**：全息青碧色与霓虹品红双色交替脉冲；
- **视觉高度**：垂直高度达 3.6 格，光柱顶端伴有放射状声波星芒粒子；
- **悬浮文字**：物品上方悬浮青色提示字样及对应的录音编号（如 `◈ 遗落的ECHO录音机 [ECHO-1-02]`），便于猎人远距离辨识定位。

### 零背包负担收录
- **不占背包槽位**：走近触碰地面的录音机即可完成拾取。即便猎人背包全部装满，也能正常拾取收录；
- **即时档案写入**：拾取瞬间地面掉落物消除，录音数据自动永久写入猎人个人终端档案库，不会转化为占格物品。

### 初次拾取与重复拾取判定
- **首次收录**：初次拾取某个编号的录音机时，屏幕弹出新收录全息警示，并**自动激活语音播放**。；
- **重复拾取**：若猎人此前已收录过该编号录音，再次拾取时仅发送简要的已收录提示，不会强制重新播放语音打扰正常战斗。

### 避难所初始引导录音
新晋猎人首次进入或重返 0 号避难所时，系统会自动进行档案核对；若尚未获得避难所初始引导录音（`ECHO-0-00` 圈层导语），系统将自动无偿发放并播送该条历史录音。

## 2. 圈层档案架构与分布

全服共收录 **45 条** 完整的历史 ECHO 录音档案，严格对应佐比克地理的九大圈层（圈层 0 至圈层 8）。

### 圈层规格与编号规则
每个圈层固定收录 **5 条** 录音档案：
- **圈层导语 (编号 `00`)**：概括该圈层的地理风貌与环境警示；
- **历史记录 (编号 `01` ~ `04`)**：展现该圈层在不同历史时期发生的重要事件与人员记录。

所有档案统一按照 `ECHO-[圈层号]-[序号]` 规则编目（例如 `ECHO-0-00` 至 `ECHO-8-04`）。

### 获取途径
1. **荒原战斗掉落**：击败荒原各圈层的狂徒或怪物时，均有概率（默认基准 2%）掉落对应圈层的遗落录音机；
2. **场景实地搜寻**：各圈层的标志性废墟、断裂缆柱、前哨站残骸等点位隐藏着专属录音；
3. **线索寻访**：在终端未解锁的录音卡片上，悬停可阅读该录音的“线索区域提示”，根据地标线索展开定向搜寻。

## 3. 猎人终端回放系统

收录进系统的录音档案可随时随地通过猎人终端进行查阅与点播。

### 呼出方式
输入 `/vh menu` 或 `/vh gui`，在主菜单点击「ECHO录音机」（唱片图标），即可进入收录面板，查看已收录的ECHO和未收录的ECHO。
