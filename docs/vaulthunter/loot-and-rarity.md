# 装备品质与掉落光柱

在佐比克废土中，所有的近战兵刃、战术弓弩、枪械、护盾、圣物、手雷模组与职业模组，均严格遵循五阶稀有度分级规范，并在生成或丢弃在地面时释放专属品质的彩色冲天光柱。

---

## 1. 五阶稀有度分级规范

| 品质分级              | 标识颜色 | 典型特征与装备定位                                                               |
| :-------------------- | :------- | :------------------------------------------------------------------------------- |
| **普通 (白装)** | 纯白     | 基础入门装备（木剑、简易皮革盾、基础石质武器），词条极少。                       |
| **非凡 (绿装)** | 亮绿     | 名厂正规军工级装备（合金锁甲盾、改良型枪械、铁质各厂武器），属性均衡。           |
| **稀有 (蓝装)** | 蔚蓝     | 具备明显厂商优势的高阶精工装备（钻石武器、增幅护盾、荒原游侠开始衍生元素型号）。 |
| **史诗 (紫装)** | 紫晶     | 特装军工顶级武器、巨兽复合装甲、顶级自适应纳米屏障与高阶战术圣物。               |
| **传奇 (橙装)** | 金橙     | 拥有独家专属传奇特效词缀（如终审、双生、孤注）或区域首领专属红字铭文的终极神装。 |

---

## 2. 彩色光柱

为便于猎人在复杂的荒原地形中快速寻宝，废土引入了微粒光柱：

![](/uploads/img-1791959435130-mve5f.png)<div style="text-align: center">五种不同品质的装备</div>

- **怪物击杀爆装**：击杀任何小怪、精英怪或领地霸主，掉落的装备在落地的瞬间立即自着地点向上延伸对应品质颜色的光柱。
- **玩家丢弃物实时光柱**：猎人从背包中丢弃（按 `Q` 键或从界面拖出）任何高阶装备时，地面掉落物同样会实时点亮对应的稀有度光柱，防止在野外与队友交换物资时遗失装备。
- **自动杂物过滤**：废土规则自动过滤原版杂物（如种子、花草、腐肉、蜘蛛线），地面仅有带光柱的高科技军火与货币代币，保持战场清爽。

## 3. 掉落率与护盾爆率平衡

为解决原版自然回血被禁用后玩家极易断护盾的问题，掉落系统进行了严格的护盾加权平衡：

- **综合掉落几率**：怪物死亡掉落装备的基础概率设定为 **35%**。
- **对等爆率池与战术配件替代**：装备掉落池基础按 **护盾 50% vs 武器 50%** 对等权重判定；其中有 15% 几率替代为圣物装备，12% 几率替代为手雷模组，10% 几率替代为职业模组（沿用当前等级与稀有度；职业模组掉落时 60% 权重智能定向为击杀者当前职业）。
- **手雷弹药掉落**：已穿戴手雷模组且手雷未满时，普通击杀有 7% 几率掉落 1 颗随身手雷弹药，首领击杀必定掉落 2 颗。
- **综合护盾掉率**：击杀任意普通怪物的实际护盾掉率约为 **13% ~ 17.5%**，确保开荒平稳过渡。
- **首领大爆 (Loot-splosion)**：击杀区域霸主时，将触发喷泉式大爆，同时喷出数十件高品质武器、护盾、货币堆与约 9% 几率的专属红字装备（含首领专属红字枪械、护盾、圣物与手雷）。
