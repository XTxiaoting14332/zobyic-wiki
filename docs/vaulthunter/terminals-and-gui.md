# 猎人终端界面

![](/uploads/img-1791957638044-fcegc.png)<div style="text-align: center">猎人终端界面</div>

## 1. 猎人个人总览菜单 (`/vh menu`)

输入 `/vh menu` ，将唤起个人控制面板：

![](/uploads/img-1791957726001-a3f8w.png)

- **中央个人体征卡片**：

  - 展示当前猎人等级、升级所需经验百分比；
  - 显示当前基础生命上限、攻击增伤乘算倍率；
  - 实时反映穿戴护盾的容量、充能延迟与速率指标；
  - 汇总当前账户持有的联邦信用币与能量秘晶余额。

---

## 2. SDU 空间折叠终端 (`/vh sdu`)

该终端专门用于消耗稀有【能量秘晶】(◆) 突破物资携带上限，分为两大核心板块：

### 背包栏位扩容区

- **展示槽位**：显示当前可用的背包空间（9格、18格、27格或36格全开）。
- **扩容按钮**：显示升级至下一阶所需消耗的能量秘晶数量。当背包槽内的秘晶满足要求时，点击按钮即可即时解开下一行背包力场锁，并伴随升级音效。

### 四大枪种备弹池扩容区

分别对应手枪、冲锋枪、步枪与霰弹枪的扩容条目：

- 每一个枪种最高支持 **5 阶扩容**，每一阶提升基础备弹量的 25%；
- 悬停图标可直观查看当前阶数（如 `Tier 2/5`）、当前备弹上限、下一阶升级上限以及所需能量秘晶（阶梯递增：4、8、14、22、32 晶核）。

## 3. ECHO 战术雷达大地图 (`/vh map` 或 鼠标右键点击罗盘)

在荒原中手持随身罗盘点击右键，或输入 `/vh map`，可唤起覆盖全废土的雷达探测面板：

- **前哨站卡片陈列**：完整列出全境 7 大战略前哨站（0号避难所、荒原着陆区、东哨卡、西哨卡、前沿营地、废弃吊桥、极地科考站、火山要塞）。
- **雷达参数动态计算**：每一个哨站图标下方实时计算并标注：
  - **激活状态**：`已激活 (可传送)` 或 `未激活 (需实地探索点亮)`；
  - **绝对坐标与推荐等级**：标明推荐进入作战的猎人等级门槛；
  - **直线距离**：当前玩家位置与该哨站之间的欧几里得直线距离（米）；
  - **八向相对方位**：如 `正东`、`西北`、`偏南` 等，指导前进方向。
- **点击追踪航标**：点击任意前哨站图标，系统将把玩家背包中的罗盘指针永久切换绑定至该哨站坐标，作为远距离行军航标。

## 4. 快速旅行网络终端 (Fast Travel GUI)

走近任何已点亮前哨站的磁石科技地台前，按下鼠标右键交互即可唤起快速旅行传送界面：

- **瞬间传送规则**：界面内仅显示玩家此前已实地走近并点亮的前哨站节点。
- **零消耗跨区域跃迁**：点击任何已点亮哨站，经过 0.5 秒空间折叠后，玩家将被瞬间无消耗传送至目标哨站的中心地台，极大节约跑图时间。

---

## 5. 黑铁军火自动贩卖机 (`/vh shop`)

输入 `/vh shop` 或与避难所自动贩卖机交互，可随时采购战备耗材：

- **平价武器货架**：陈列各厂商的基础白装/绿装近战刀剑、基础短弓与巡逻轻弩，供意外遗失装备的猎人快速补齐武装。
- **专用弹药货架**：
  - 手枪弹药包（40 发/包）
  - 冲锋枪弹药包（80 发/包）
  - 突击步枪弹药包（60 发/包）
  - 霰弹弹药包（16 发/包）
- **医疗急救货架**：出售 `军用急救医疗包`（单价 120 信用币）。右键使用立即恢复大量生命值，是荒原无自然回血环境下的保命核心。
- **备用基础护盾**：出售基础 `简易皮革护盾`（单价 80 信用币，50 容量），防止玩家因护盾破损且无替换件导致肉身挨打。
