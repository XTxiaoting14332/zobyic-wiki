# 屏幕状态栏

为了在原版 Minecraft 界面中还原硬核 ARPG 的战斗沉浸感，《宝库猎人》全面接管了屏幕动作栏（Actionbar）、浮动信息与飘字渲染系统。

---

## 1. 实时状态栏

玩家进入废土世界后，屏幕正下方 Actionbar 将常驻状态栏：

**Actionbar 显示样式：**

![](/uploads/img-1792493005500-igflj.png)

各模块详细说明如下：

1. **蓝色护盾条**：

   - 实时指示当前护盾数值与最大容量，并附带动态进度方块。
   - 当护盾被敌人火力击碎归零时，该模块立即替换为闪烁的红字告警：`[ 🛡 破损! ]`。
2. **红色生命条**：

   - 显示当前真实生命值与上限。
   - 随着猎人等级提升，基础生命上限提升（每级 +2 HP），此处最大值与心数动态递增。
3. **等级经验**：

   - 指示当前猎人等级。
4. **弹药计数**：

   - 当手持弓、弩或枪械时触发显示；
   - 显示备弹池弹药。
5. **手雷储备**：

   - 装备了手雷模组时常驻显示；
   - 指示当前随身手雷储备与携带上限。

## 3. 战场 RPG 浮动伤害飘字

每一次武器挥砍、爆头射击与元素 DoT 触发，均会在被命中敌人头顶精确生成实时的浮动文字：

- **标准动能伤害**：醒目红色数字（如 `-15`），代表常规非克制命中。
- **手雷爆炸伤害**：亮黄数字伴随炸弹标识（如 `-150 💣`），代表受到手雷模组主爆炸或派生子雷杀伤。
- **暴击跳劈 / 爆头弱点**：加粗亮金数字伴随爆破粒子（如 `-28 💥`），代表触发弱点暴击。
- **元素持续伤害 (DoT)**：
  - 燃烧：橙红烈焰飘字；
  - 酸蚀：鲜绿酸雾飘字；
  - 电击：浅蓝电火花飘字。
- **越级刮痧判定**：当玩家越级挑战高阶敌人时，飘字呈现为灰色护盾图标（如 `[刮痧] -2 🛡`）。
- **极度危险告警**：跨越 5 级以上挑战深层敌人时，受击怪物头顶强制顶出 `☠ 极度危险` 警告标识。

## 4. 殊死一搏 (FFYL) 濒死生命倒计时条

当玩家受到致死打击进入 FFYL 跪地状态时，屏幕正上方显示倒计时：

- 倒数条由满格向零快速萎缩；
- 若在此期间完成二次呼吸或战友急救，倒数条立即撤销。
