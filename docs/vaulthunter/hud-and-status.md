# 屏幕状态栏

为了在原版 Minecraft 界面中还原硬核 ARPG 的战斗沉浸感，《宝库猎人》全面接管了屏幕动作栏（Actionbar）、浮动信息与飘字渲染系统。

---

## 1. Actionbar 战场实时状态栏

玩家进入废土世界后，屏幕正下方 Actionbar 将常驻渲染五大生理与战备核心指标：

**Actionbar 显示样式：**  
`[ 🛡 150/150 ■■■■■■ ]` `[ ❤ 24/24 ❤❤❤❤❤❤ ]` `[ ⚡ Lv.3 45% ]` `[ 💵 $1,250 ◆3 ]` `[ 🏹 45/100 ]`

各模块详细说明如下：

1. **蓝色护盾条 `[ 🛡 150/150 ■■■■■■ ]`**：
   - 实时指示当前护盾数值与最大容量，并附带动态进度方块。
   - 当护盾被敌人火力击碎归零时，该模块立即替换为闪烁的红字告警：`[ 🛡 破损! ]`。
2. **红色生命条 `[ ❤ 24/24 ❤❤❤❤❤❤ ]`**：
   - 显示当前真实生命值与上限。
   - 随着猎人等级提升，基础生命上限提升（每级 +2 HP），此处最大值与心数动态递增。
3. **黄色等级经验 `[ ⚡ Lv.3 45% ]`**：
   - 指示当前猎人等级以及升入下一级所需的击杀经验进度百分比。
4. **绿色经济储备 `[ 💵 $1,250 ◆3 ]`**：
   - 左侧为当前账户的联邦信用币余额，右侧为持有的能量秘晶数量，方便随时查看。
5. **金色弹药计数 `[ 🏹 45/100 ]`**：
   - 当手持弓、弩或各类现代枪械时触发显示；
   - 格式为 `[当前弹匣已装填弹药 / 随身备弹池剩余弹药]`。

## 2. 智能弹窗缓冲保护 (Alert Buffer)

在常规刷新中，状态栏保持高频平滑更新。为了防止重要突发事件提示被状态栏瞬间冲刷覆盖，系统内置了 2.5 秒独立高优先缓冲逻辑：

- **货币变动提示**：拾取地面金币时，屏幕立即弹出醒目的 `+$15 信用币 [余额: $1,250]`。
- **弹药与背包告警**：备弹耗尽时弹出 `[ 警告: 弹药已耗尽! ]`；可用槽位装满时弹出 `[ 提示: 快捷栏已满，无法拾取装备! ]`。
- **高优先保护机制**：上述提示在触发后享有 **2.5 秒专属驻留时间**，在此期间常规 HUD 状态栏暂时静默退让，确保玩家清晰读取事件信息。

## 3. 战场 RPG 浮动伤害飘字

每一次武器挥砍、爆头射击与元素 DoT 触发，均会在被命中敌人头顶精确生成实时的浮动文字：

- **标准动能伤害**：醒目红色数字（如 `-15`），代表常规非克制命中。
- **暴击跳劈 / 爆头弱点**：加粗亮金数字伴随爆破粒子（如 `-28 💥`），代表触发弱点暴击。
- **元素持续伤害 (DoT)**：
  - 燃烧：橙红烈焰飘字；
  - 酸蚀：鲜绿酸雾飘字；
  - 电击：浅蓝电火花飘字。
- **越级刮痧判定**：当玩家越级挑战高阶敌人时，飘字呈现为灰色护盾图标（如 `[刮痧] -2 🛡`）。
- **极度危险告警**：跨越 5 级以上挑战深层敌人时，受击怪物头顶强制顶出 `☠ 极度危险` 警告标识。

---

## 4. 殊死一搏 (FFYL) 濒死生命倒计时条

当玩家受到致死打击进入 FFYL 跪地状态时，屏幕正上方自动唤起全屏 BossBar 生命体征倒数条：
- 倒数条由满格向零快速萎缩，代表大脑神经休克倒计时；
- 若在此期间完成二次呼吸或战友急救，倒数条立即撤销并播放复苏音效。
