# 世界观与背景故事

佐比克（Zobyic）是位于银河边缘第三象限的一颗矮行星。该行星拥有极高的重金属矿藏与远古埃里迪安超空间文明遗迹。游戏的核心叙事与机制设定均围绕其地质灾难、企业殖民史与遗迹发掘展开。

---

## 星历编年史记

佐比克星的发展历史分为四个主要阶段：

### 1. 开拓与掘金时代（星历 214~248 年）
- **行星勘探与定名**：深空巡航舰在银河联邦拓展星图边缘捕获矮行星 Z-209。光谱分析确认其地壳深处蕴藏前所未见的高能辐射脉冲，随后联邦将其定名为“佐比克”。
- **五大寡头瓜分地表**：各大星际军工企业成立特遣采矿队蜂拥而至：
  - **先锋重工** 占据中央台地，修筑跨大陆运输与通讯干线；
  - **泰坦动力** 在中部山脉铺设高压蒸汽重炉与深井矿井；
  - **天穹化学** 建立地下合成实验室，解析辐射元素；
  - **掠食生物** 与 **荒原游侠** 分别在边境设立异种培育所与独立武装哨卡。
- **埃里迪安方尖碑出土**：地下四千米深处发掘出非自然几何结构的紫色方尖碑。碑体蚀刻着高维能量回路，释放出稳定的微观空间扭曲能量。该晶核物质被正式定名为“能量秘晶”。

### 2. 大灾变与紫穹脉冲（星历 249 年）
- **“第七深井”贯穿事故**：泰坦动力与天穹化学联合推进超深地热钻探，高压合金钻头意外穿透了远古埃里迪安重力井核心。
- **紫穹脉冲爆发**：地底暴涌而出的高能冲击波席卷整颗行星平流层，造成不可逆的灾难后果：
  - **碳基生态灭绝**：脆弱的水循环系统彻底破坏，牛、羊、猪、禽类等常规温顺生物在数分钟内因基因链崩溃而灭绝；
  - **同心圈层断裂**：引力异常震碎地壳，以深井为中心形成同心环状断裂带，从中心向外依次崩裂为干旱荒原、强盗峡谷、变异冻原、工业带、火山要塞、裂谷与晶簇群；
  - **晶化粉尘污染**：大气中充斥着高吸附性的微观晶核孢子，导致碳基生物无法进行常规胃肠消化（促成了后续代谢静滞阀门与能量护盾技术的应用）。
- **企业大撤退**：灾难发生后，五大财团高层搭乘超光速穿梭舰撤离地表，遗弃了数以万计的底层矿工、机械工程师与雇佣守卫。

### 3. 狂徒化与混乱割据（星历 250~267 年）
- **社会结构瓦解**：地表幸存者陷入原始的物资争夺，演变为极度崇尚暴力的荒野掠食部落。遗留在各基地的民用与军用机甲遭到拆解改装，守备铁傀儡在恶意芯片刷写下退化为狂暴的巨型坏蛋劫掠兽。
- **0 号避难所升空**：流亡技术人员在中央台地彻底沦陷前，启动了先锋重工遗留的城市级反重力浮空引擎，将数万平方米的中央广场送入近地轨道虚空，建成废土上唯一的非武装中立空港——0 号避难所。

### 4. 宝库猎人狂潮（当前纪元）
- **远古宝库证据确凿**：轨道探测卫星证实，佐比克星地核深处存在一座真正的先民遗迹——埃里迪安远古宝库，传闻封存着宇宙先驱者的终极科技构装体。
- **New-U 协议与雇佣兵招募**：先锋重工重组轨道舰队，但拒绝派遣昂贵的正规军登陆清剿，转而在全荒原空投密集部署 3×1 New-U 量子重构立柱，并向全银河发布通缉协议：
  - 允许赏金猎人保留在废土搜刮到的全部军火与财宝；
  - 猎人阵亡时由 New-U 网络从原子尺度重构身躯，先锋重工仅按次扣除 7% 现金作为数字化服务费。
- 成千上万的雇佣兵、逃犯与冒险者（统称“宝库猎人”）经由避难所空投地表，荒原进入全天候高频交火的刷宝淘金时代。

## 废土主要势力阵营

大灾变与大撤退后，佐比克形成了以 0 号避难所中立空港为中枢、地面狂徒军阀与外星构装体割据的阵营格局：

| 组织 / 势力 | 代表人物 / 据点 | 职能定位与行为模式 |
| :--- | :--- | :--- |
| **避难所自由商盟** | “火药桶”加里 / 避难所商业街 | 维持 0 号避难所运转的中立商人集团，通过自动贩卖机网络向猎人供应武器弹药与医疗包，只认联邦信用币。 |
| **走私联合体** | “铁肺”鲁多克 / 避难所管道区 | 掌握高维空间压缩技术的黑市组织，独家经营 SDU 空间扩容终端，拒收信用币，仅以能量秘晶作为升级硬通货。 |
| **荒原掠食强盗** | 九指拉格纳、狂人巴恩 / 峡谷据点 | 由灾后遗弃劳工异变而来的武装强盗，占据关卡哨塔，崇拜机械暴力并主动伏击过往猎人。 |
| **失控先锋执行军团** | 威尔海姆·执行者 / 强盗峡谷 | 先锋重工撤退时丢弃的重装机械改造人部队，核心逻辑芯片受损后无差别清除一切靠近的非授权碳基生命。 |
| **埃里迪安构装守卫** | 终焉守卫者 / 宝库核心遗迹 | 远古高维文明留存的高能等离子构装体，常年处于休眠状态，负责无差别抹杀试图解开宝库封印的入侵者。 |
